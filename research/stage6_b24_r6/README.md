# Stage6 R6 单调高度头部延伸：研究，不是已通过的布偶

R5 在 40 帧原生 Blender Cloth 中确有形状改善，但它的两侧延伸片预定位高度为 `230→240→230→235→245 mm`，中间沿 Z 轴折回。实际求解后的自穿插尚没有独立否决门禁。

R6 只改变原始两侧高位延伸布片的预定位与对应二维静止参数，采用 `230→231→232→235→245 mm`；原 Stage6 235/245 mm 截面高度保留，原 230 mm 侧片截面只作为 232 mm 的研究中间轮廓，并非真源直接切缝。其他结构不变：40 研究裁片、旧 R3 的 986 条弹簧与全部 R5 的 1170 条弹簧身份保持，4块原 Stage6 耳片仍未真正缝入。

生成器以新 `bridge_builder` 参数复用 R5 的实际布片求解和配缝逻辑；不调用动态补丁、不修改 R5 默认实验。同一次受信 `main` Stage6 Blender 4.3.2 工作流生成旧 R5 与新 R6 各40帧求解结果，保留两套独立证据与 GLB。为兼容现有已验证求解器，新 R6 的部分源文件和 Blender 内部网格名称仍使用 R5 兼容格式；`R6_MONOTONE_BRIDGE_PROVENANCE.json` 固定其真实来源，不能把其中某个 R5 名称理解为旧 R5 结果。

结果门禁必须分层：源哈希/40件/净缝、静止边到三维边变形、真正 Blender evaluated 网格外形/缝隙、非邻接三角面独立接触、自碰、材料和实物。仅因高度单调或预定位相交减少绝不认定真实模拟通过，更不能认定正式纸样或工厂产品；P3仍在进行、P4未开始、正式工业裁片0。
