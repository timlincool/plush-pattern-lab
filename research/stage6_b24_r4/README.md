# Stage6 R4中央头冠改版：真实二维裁片与物理 A/B

R4仍是24片研究软布壳，保留R3的四蹄、身体、颈部及986条缝合弹簧，不是新工厂纸样。

原Stage6在Z230与Z234有中央头冠及左右两个高位突出，共三条独立闭环；R3中央顶盖是单层64面扇形。R4保持顶盖与四个HEADNECK围片的原64点外圈、原二维净线与所有986弹簧不变，仅将顶盖内部添加一层Z234的64点新材料网格。源截面只以50%逐步贴近，以拒绝原几何100%贴合导致的材料大变形。顶点2635→2699，面数1990→2054；仍然只有24研究裁片，未缝两个侧高部件。

独立本地验证：940对实际存在的二维配缝段最大差≈2.9e-13mm；新增顶冠局部预定位边长变形P95≈9.10%，全件约10.37%，最大仍约62.66%。本次研究的真实最终形状必须以Blender evaluated第40帧为准，不可据预定位宣布改进。

在现有受信 Stage6工作流中同次执行R3→R4原生Blender Cloth40帧与固定源PLY形状/中央头顶分区、拼缝、应变 A/B；原跑法为零重力、无填棉压力、无自碰，保证严格同条件。头部形状恶化即保存失败反例。两侧源高突出、七云、耳根和尾巴仍未创建真正二维接缝和厂家工艺。
