# R7：头冠根部先抬升、后侧向展开（仅研究）

R6 真正Blender40帧的残余非缝合接触共21组，其中新增头壳↔旧主壳15组，集中在右侧头顶根部 X≈22/Y≈−49/Z≈226–227mm；R6原侧头片几何从X≈12到≈40mm仅跨越230→231mm这一层，非常平躺，容易与原头冠面片重叠。

R7仅改变两侧侧头延伸片的五个三维定位站位为 **230→232→234→235→245mm**，并将前两层横向插值改为源z230侧轮廓的12%/46%：先抬升，再展开。原 Stage6 z235/z245截面坐标仍按源曲面使用，原z230侧轮廓由R7以z234研究代理传递，不伪称原始真实开缝。

保持原R3下部2635个顶点完全不变，保留R5/R6的 **40研究裁片、1170条相同弹簧配对**，使用相同的R5二维Rest Shape构建器及Blender4.3.2 Cloth求解器，不改R5默认方案。没有任何原场景耳朵、云朵、尾巴被新增物理缝合。输出中 `R5_SOURCE_...` 等名称是历史求解器兼容名；R7独立`R7_ROOT_TRANSITION_PROVENANCE.json`锁定方案身份和SHA，不能把预定位当求解。

本地独立研究检查：40件/1170弹簧，新增二维配缝最大误差3.12×10^-6 mm；预定位整体材料边长变形P95≈8.824%（原阈值10.5%），新增布片P95≈1.623%；保守非理论缝合邻接初始三角面交/触筛检=0。**这不是物理第40帧碰撞结论。**

受信`main`原Stage6工作流在同次运行 R6/R7 各求解40帧，R7结果以真实evaluated mesh对比原 Stage6的形状、缝隙、材料；之后须另做第40帧有限非邻接接触检验。压力填棉、动态自碰、实测材料、工厂纸样全未验证。**P3进行、P4未开始、正式工厂纸样0**。
