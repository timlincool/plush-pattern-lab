# Stage6 B24 R2 — 真实源截面驱动的可缝研究迭代

## 为什么做 R2

旧 B24→R1 已经在同一可信 Stage6 Blender 4.3.2 工作流（Run #43586275422）完成物理 40 帧求解：双向抽样平均表面误差由 7.515mm 降到 6.953mm，但躯干仍偏盒状、头顶侧突出无真实缝合。R1 按截面**面积**拟合，未精确拟合平面轮廓。

R2 固定原 Stage6 25% 主壳 PLY 的 SHA，逐高度读取真实多连通切线：115/125mm 身体；155/180/205/230mm 头颈与中央顶盖；**125mm 有两个闭合分量、230mm 有三个**，R2 只用面积最大的主环，不虚构旁侧突起布片。原 100mm 下围、135mm 肩外圈、145mm 颈口和 13 块下部源锚定件原样保留。

## 有约束的安全系数

研究中直接按 70% 的源轮廓移动身体 115/125mm 时，二维 Rest→三维预定位出现某些边长误差大于 1000%，严禁采纳。当前选择 115mm 25%、125mm 40%、头颈 155/180/205/230mm 各 70%，理由是先给形状收益、同时让初始表面边长变形 P95 <10.5%、最大 <75%；门禁由同次 Runner 重算。**这只是数字预定位的应变筛查，不是实测材料强度批准。**

## 真正的物理 A/B

复用仓库现有（已白名单）`.github/workflows/stage6-hoof-seam-reference.yml`，不创建新 GitHub Actions 工作流。步骤：同次受信 Stage6 源网格→原 B24→R1→R2 二维真实静止裁片→同参数原生 Blender Cloth 40 帧→独立解析两个 depsgraph 网格，用同一源 PLY 做固定种子 15000 面采样双向近邻（mean/P95）及 974 弹簧间距、2D Rest 实际边伸长 P95 对照。最终证据 `stage6_b24_r2_physical/solver/B24_R2_vs_R1_REAL_Blender_AB.json` 和真实物理 `B24_R2_REAL_Blender_Cloth_frame40.glb`。

任何 R2 实验执行失败保留失败，不能将 R1 文件复制或当作 R2 物理结果。真实耳朵、云团、尾巴、颜面、雨滴、自碰撞和填棉仍未完成；P3 进行中，P4 未开始，厂商批准纸样 0。
