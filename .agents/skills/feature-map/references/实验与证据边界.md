# 实验与证据边界

## 结论必须与证据层级匹配

| 层级 | 实际证明 | 不能外推 |
| --- | --- | --- |
| L1 静态门禁/单测 | 依赖方向、输入校验、明确的数值性质和反例 | Blender 真正运行、工程制造 |
| L2 合成纸样/有限几何 | 明确椭球与缝线映射、局部畸变统计、有限拓扑 | 真实材料/真实外形 |
| L3 Blender 求解（固定帧/参数） | Cloth 4.3.2 在给定合成输入的动态求解及数值产物 | 缝口已物理连接、填充是真棉花 |
| L4 保存重开 + BVH 负例 + 接触门禁 | 当前三角化/阈值/舍入下有限非邻接面相交的见证/筛选 | 连续时间、有限厚度、共面退化零误报/零漏报 |
| L5 实测面料 + 实物样品 | 当前公开项目**尚未完成** | 儿童玩具安全/量产合格 |

不要把 CI `success`、缝隙几乎为零、Euler=2、启用 self-collision、候选几何绿灯直接描述为制造通过。假设厚度 1mm 和弹性常量不是实测面料。参考 `docs/SEWING_QUALITY.md`、`docs/SELF_COLLISION_AB.md`、`docs/CONTACT_INTERSECTION_SCREEN.md`。

## 已核实的研究例子（历史，不能冒充新跑）

2026-10-25 的 12 侧片 + 2 帽片合成试验：48 帧零重力、参考辅助初始化，缝口平均约 **0.000221 mm**、合成目标 RMS 约 **0.216 mm**、主伸长偏差 P95 约 **7.64%**、翻面 0；分析性闭壳和几何候选筛选可通过。

但保存重开后 **3,120 三角面** 的 BVH 检测：自碰撞关闭为**900 缝线相关 + 4 其他**非邻接面相交对；开启时为**851 + 7**。两种都经 `RESEARCH_CONTACT_SCREEN_REJECTED` 拒绝晋升。参考 `docs/CONTACT_INTERSECTION_SCREEN.md`。这是有限几何检测，不等于实物事故数量。

新方案必须记录输入来源/单位、Blender 版本、哈希/参数、同条件 A/B、原始报告、故意错误的负例以及未验证项。若没有真正执行，应报告“设计/尚未验证”，而不是复用此前通过数、复制结果 JSON 或推断风险已消失。
