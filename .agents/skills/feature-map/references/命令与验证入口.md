# 命令与验证入口

从仓库根目录、使用可信源码运行。**只读外部 PR 时不得执行其修改后的命令。**输出使用全新的目录/文件，避免覆盖历史证据。项目要求 Python 3.11+；Blender 任务使用已验证的 4.3.2。

## 安装与纯 Python

```bash
python -m pip install --only-binary=:all: -r requirements-dev.txt
python -m pip install --no-deps --no-build-isolation -e .
python scripts/check_quality.py
python -m pytest -q
```

修改 CLI/包时，追加 `python -m compileall -q src scripts tests` 和 wheel 构建；以 `.github/workflows/ci.yml` 为准。质量入口目前要求 Ruff C901≤10、PLR0912≤12、PLR0915≤50、文件≤2000行、包内无循环依赖；Git 暂存检查 `python scripts/check_quality.py --staged` 只用于可信本地 Git 克隆，不会由 API 形式提交自动触发。

## 可复现合成案例

```bash
mkdir -p /tmp/plush-lab-study
python scripts/capped_gore_pattern.py --panels 12 --pole-cut-deg 8 --out /tmp/plush-lab-study/capped.json
python scripts/export_capped_svg.py --input /tmp/plush-lab-study/capped.json --output /tmp/plush-lab-study/capped.svg
python scripts/plush_gore_pattern.py --radius-mm 55 --half-height-mm 70 --panels 12 --segments 64 --out-prefix /tmp/plush-lab-study/gore
python scripts/material_calibration.py --input examples/synthetic_swatches.json --output /tmp/plush-lab-study/swatches.json
```

现有 `scripts/` 命令保留兼容；安装后的 `plush-capped-gore` 等入口见 `pyproject.toml`。以上为合成输入，**非真实面料验证**。

## 第一次实际裁剪与试缝

~~~bash
python scripts/capped_gore_pattern.py --panels 12 --pole-cut-deg 8 --out /tmp/plush-pattern.json
python scripts/build_prototype_kit.py --input /tmp/plush-pattern.json --output-dir /tmp/plush-printable --paper A4
~~~

打印每张 sheet-*.svg 时固定 100%/实际尺寸，逐页核对 10×10mm 方框。输出为逐片裁切/缝线/对位/返口标记与中文试缝说明；只适用合成椭球，真实羊驼纸样和材料试验尚未认证，具体见 docs/PHYSICAL_PROTOTYPE.md。

## Blender 独立证据

所有 Blender 命令加 `--disable-autoexec --python-exit-code 1`；真实产物在 GitHub Hosted Runner 或没有机密的隔离环境生成。固定工作流：

| 目的 | 可信 CI 入口 |
| --- | --- |
| 普通 2D 裁片真实缝合 | `.github/workflows/sewing-poc.yml` |
| 8/12 片 + 两帽片真实缝合 | `.github/workflows/capped-sewing.yml` |
| 自碰撞对比、保存重开、有限面相交审计 | `.github/workflows/selfcollision-ab.yml` |
| 纯 Python 质量 + 85 项历史基线测试与 wheel | `.github/workflows/ci.yml` |

历史 85 项是合并提交 `71b5d690` 的结果；不得用于证明新提交未运行的测试。对应一次正式合并后的 CI 为 `40262586414`；Blender 三工作流分别为 `40262586512`、`40262586393`、`40262586410`（需按 GitHub 最新运行核对）。

研究候选门禁：`python scripts/assess_research_candidate.py --report REPORT.json --output GATE.json`。接触否决门禁：`python scripts/assess_contact_integrity.py --simulation-report SIM.json --triangle-report TRIANGLES.json --output CONTACT.json`。只有显式尝试将研究候选晋升时才加 `--require-pass`；普通收集实验报告不应因科学上的“拒绝”被误报为程序失败。

公开仓库禁止将私人 `.blend`、个人目录、真实凭据和公司资料用于 Actions。更多参数必须读本仓库 CLI 源码与对应工作流，不臆造命令行选项。
