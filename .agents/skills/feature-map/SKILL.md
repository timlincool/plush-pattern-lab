# Plush Pattern Lab · 当前功能地图

当用户问“哪里实现、有什么、怎么用、进展如何、下一步改哪”时，先看此页，按需仅打开对应 reference。**以当前源码和匹配的 CI 结果为准，不把计划、旧实验或运行成功当作新的能力证明。**

## 现有能力与边界

| 能力 | 当前证据/范围 | 不代表 |
| --- | --- | --- |
| 2D 侧裁片、8/12/更多参数化分片 | 合成椭球净缝线、缝份、对位信息、1:1 SVG，数值校验 | 任意照片自动转换、真实物料裁片 |
| 顶/底独立帽片 | 对应侧片端缝线的有向配对，8+2/12+2 合成研究 | 实际无折痕、可缝合制造 |
| 经/纬材料试片 | 批次和单位检查、加载卸载、刚度/滞回计算；提供合成样例 | 真实布料已标定、已生成 Blender 本构 |
| 布料数值质量 | 缝隙、目标辅助刚体对齐 RMS、离散 Chamfer、主伸长、翻面 | 真实外观还原/连续曲面距离保证 |
| Blender 4.3.2 仿真 | 48 帧合成缝合，自碰撞 ON/OFF；独立重开保存场景 | 真实填棉、缝线受力认证 |
| 闭壳拓扑/交叉门禁 | 理论顶点身份焊接、BVH 非邻接三角面相交、来源哈希与接触否决 | 无自交、无厚度接触、生产合格 |
| 工程质量 | Python 正式包、Ruff/圈复杂度/分支/语句/行数、AST 依赖与单元测试 | CI 可审计所有不可信 PR、代码形式化安全 |

**关键现状：** 已知合成 12 侧片 + 双帽片在研究几何门禁上可以通过，但保存后 3,120 三角面的非邻接交叉审计仍检出穿插，接触晋升门禁拒绝。不能仅凭缝口极小、欧拉数或 `self_collision=True` 宣称“已可生产”。
