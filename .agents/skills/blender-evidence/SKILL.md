# Blender 仿真与证据晋升

**触发：** 涉及 `src/plush_pattern_lab/blender/`、布料力学参数、模拟帧、模型保存/重开、接触检测、声称几何/生产通过。先读 [可执行实验与否决链](references/可执行实验与否决链.md)。

- 默认使用 Blender **4.3.2**；只在维护者可信的 Runner/隔离环境运行已审核代码，官方二进制校验哈希。绝不在含私有文件与凭据的工作站执行未知 PR 的 `.blend`、Python、附件或依赖。
- 比较保持同裁片与端缝线、同初始化、同帧数、同软件与材料假设，仅一次改一个变量。参考辅助 3D 预定位必须明确标识；不能声称是未知真实目标自动重建。
- 求解结果分别报告：缝口、目标形状 RMS/离散 Chamfer、2D 静止裁片到 3D 主伸长、法线翻转、理论焊接拓扑、BVH 相交见证、接触否决。
- 数值执行成功不等于几何门禁通过；**几何门禁通过也不等于接触门禁通过**。保存 `.blend` 和 JSON 后独立重开验证，检查来源哈希；失败案例和否决报告须保留。
- 变更验证应先跑纯 Python 质量/测试，再执行可信 Blender A/B 与反例。未执行 Blender 时不应声称物理回归通过。

尚没有实测材料、填料压缩/回弹或实物缝制证据，不能宣布生产/儿童玩具安全通过。
