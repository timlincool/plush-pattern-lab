# 可执行实验与否决链

## 仿真链路与真实入口

```text
合成纸样 JSON (capped_gore_pattern.py)
      ↓ Blender 4.3.2, 真实 2D rest_shape_key + sewing springs
保存 trial.blend 与 trial.json
      ↓ independent shape/strain and theoretical welded topology
assess_research_candidate.py → RESEARCH_GEOMETRY_SCREEN_PASSED / RESEARCH_CANDIDATE_REJECTED
      ↓ Blender 独立重开快照及 BVH 非邻接三角面
audit_self_intersections_blender.py → triangle-report.json
      ↓ 绑定仿真报告哈希、逐项验证计数
assess_contact_integrity.py → RESEARCH_CONTACT_SCREEN_REJECTED / FINITE_TRIANGLE_CONTACT_SCREEN_CLEAR_NOT_CERTIFIED
      ↓ 实测面料、裁缝打样、适用法规测试（当前未实现）
不得自动“合格量产”
```

主分支可信工作流：`.github/workflows/sewing-poc.yml`、`.github/workflows/capped-sewing.yml`、`.github/workflows/selfcollision-ab.yml`。来源为 `src/plush_pattern_lab/blender/sewing_poc_blender.py`、`sewing_capped_poc_blender.py`、`audit_self_intersections_blender.py`，保留原 `scripts/` CLI。

## 必须一起看的变量与负例

| 项目 | 要记录或校验 |
| --- | --- |
| 来源 | 源文件 SHA-256、合成还是授权素材、Blender 版本、参数、输出提交和 Actions 运行号 |
| 初始条件 | 2D 静止长度、参考辅助 3D 初始位置、帽片数/缝线关系、重力 0 或真实重力 |
| 形状/材料 | mean/max seam gap（mm）、目标辅助 RMS（mm）、P95 主伸长偏差、面片翻面、材料假设 |
| 拓扑 | 开边、非流形/朝向冲突、Euler、理论焊接身份（不等于物理焊接） |
| 接触 | BVH 非邻接面相交，区分缝线相关与其他；故意相交与隔空三角面、共享边和缝线身份的 canary |
| 阈值 | 研究默认形状 2mm、主伸长 10%、翻面 0 等只是工程筛选，不是实物布料标准 |

研究筛选返回 `RESEARCH_GEOMETRY_SCREEN_PASSED` 仅表示其有限条件满足。若 `RESEARCH_CONTACT_SCREEN_REJECTED`，即使所有其他质量检查通过也不能宣传“无交叉”。没有检测到有限三角片相交也不能推论厚度、连续时间与共面退化完全安全。

## 只读执行与产物

仅在可信运行器，固定参数、**目标输出不存在**时执行；运行 `blender --disable-autoexec --python-exit-code 1 -b -t 2 --python scripts/sewing_capped_poc_blender.py -- --spec ... --output ... --report ... --frames 48`。实际路径用 `docs/ARCHITECTURE.md` 与工作流确定，不将省略号原样执行。

之后用 `scripts/verify_bvh_intersection_canary.py`、`scripts/audit_self_intersections_blender.py`、`scripts/assess_contact_integrity.py` 分开核验，`--require-pass` 仅用于明确的候选晋升。Python 质量门禁 `python scripts/check_quality.py` 必须先运行。

目前的有限测试基线及交叉否决情况见 `docs/CAPPED_PATTERN.md`、`docs/SEWING_QUALITY.md`、`docs/SELF_COLLISION_AB.md`、`docs/CONTACT_INTERSECTION_SCREEN.md`。这些历史报告不能代替对新提交的重复实验。
