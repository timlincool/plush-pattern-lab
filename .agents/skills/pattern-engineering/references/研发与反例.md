## 对抗性场景

- 缝线对应：逐段比对端点/长度与 seam identity，故意制造缺边、错向、同点退化、帽片半径零/面片穿插；只比“总周长相等”不足以保证逐段缝合。
- 纸样与形状：完美闭合的两片放大 25% 后仍必须因为目标偏差/主伸长被识别，不能单用缝口间隙判定成功；保留 8/12/帽片的成本与畸变权衡。
- 材料：经/纬数据独立，采用 `length_mm` 与 `force_N`，核对标距、单调加载/卸载、质量 `gsm`、厚度 `mm`、批次来源和非物理负力。示例 `examples/synthetic_swatches.json` 是**合成**，不因为字段 `data_origin=measured` 就认证真实来源。
- 输出：毫米标注的 SVG 可被打印为 1:1 仅是格式要求，不包含裁布收缩公差、纹理方向现实检测、授权/安全认证。旧 JSON 字段、单位和输出拒绝覆盖历史文件的行为必须保留。

## 最小可运行样例

```bash
python -m pytest -q tests/test_gore_pattern.py tests/test_capped_gore_pattern.py tests/test_export_capped_svg.py tests/test_material_calibration.py
python scripts/check_quality.py
```

需要实际走裁片→保存模型→接触否决时，先查看 `blender-evidence`，不能仅因本组 Python 测试通过便跳过 Blender 验证。

工程文档：`docs/GORE_PATTERN.md`、`docs/CAPPED_PATTERN.md`、`docs/MATERIAL_CALIBRATION.md`、`docs/PATTERN_TRADEOFF.md`。
