## 已有真实几何基线

公开原 Blender SHA-256 为 38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a；原四蹄真实源口不变。上轮在固定 25% 源代理 PLY（59,306 顶点、116,568 真三角面）而非单层包围盒上，重建 13 个高度的实际三角面交线：

- **Z125：2 条闭环**。后部独立小轮廓不能被一条躯干围片包络。
- **Z230：3 条闭环**。中央周长约 153.094 mm，左右各约 45.517/45.511 mm；旧 A/B 一条周长约 319.77 mm 的头顶盖不能代替。
- **Z245：2 条闭环**。中央轮廓消失，左右侧小环仍存在。

这些环属于**主壳源代理**。原完整 41 产品 Mesh 中另有外/内耳、胸云、头云、额云、尾巴、五官、蹄部等独立对象；不能凭名称或最近距离认定主壳侧环属于耳朵或云团。

## 本轮新门禁与重现实验

1. 同次真源 summary/detail JSON 必须具备固定来源 SHA、detail 字节 SHA 和 Z125/230/245 的 2/3/2 环；不接受外部 PR 模型或跨实验复用文件。
2. 每环保留原源交边的两个 Vertex ID、真实 XY、Z、周长和逐环 SHA。每环最多**确定性抽取 48 个源交边点**，分别记录总交边数和采样数；不能冒称全部顶点经过 Mesh 检测。
3. Blender 4.3.2 基于原公开场景的 **41 个产品 Mesh** 构建世界坐标三角面 BVH，排除摄影棚地面。以 **6 mm** 半径查询截面点周围**其他 40 个独立 Mesh**；以 **3 mm** 界限分离零候选、单候选、多候选。包围盒只做加速，不能充当真实几何接触证据。
4. 对完整 41 产品 Mesh，在正、背、左、右、顶五个方向作原始三角面首表面 raycast，分别记录首先命中的对象和深度类别。毛发曲线、渲染修改器、面料厚度、成品遮挡与机器刺绣**均不在验证范围**。
5. 输出每环每个源交边采样的 Vertex ID、邻近对象及真实三维距离、五视角首命中及分类 JSON；CI 强制所有源环完整，并禁止“最近对象即工艺归属”或 P3/P4 自动晋升。

实现路径：src/plush_pattern_lab/validation/stage6_section_mesh_correspondence.py；src/plush_pattern_lab/blender/audit_stage6_section_mesh_correspondence.py；scripts/audit_stage6_section_mesh_correspondence.py。真实执行入口为 .github/workflows/stage6-hoof-seam-reference.yml，仅可信 main 分支。

## 判断与下一门禁

**即使源环到某耳部 Mesh 的原三角面距离为零，也只证明两套视觉几何接近**，不证明耳根、内外耳缝份、覆层遮挡或实体接合。必须另用原设计与 D 参考对照正/侧/背/顶视角，进一步制定中央头盖、侧突出独立片、隐藏缝、3D↔2D 配缝、翻面与填充工序，再制作真实废布样。
