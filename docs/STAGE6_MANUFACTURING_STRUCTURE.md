## 主壳真实曲面拓扑与后续减面安全门禁

在直接生成低密度代理之前，先执行 [Stage6 主体全部 466,278 面的连通性/边界/非流形审计](STAGE6_CORE_SHELL_TOPOLOGY.md)。真实主壳的全部拓扑结果将决定保护四蹄 512 点环的无损分片方案。**拓扑检查不会改原模型、不自动生成可缝裁片，也不等于 P3 完成。**

## 第一批真正要开始画的结构：主壳＋四腿／四蹄

不是继续微调四蹄环带权重，而是开始**整件主壳的可制造分割**：

1. 在固定来源的 Stage 6 主体网格建立较低面数的**制造几何代理**，保持外观轮廓与四个已证实的开放接缝环；不得直接对原 466,278 面高密度壳做不可逆破坏。需要用同视角和毫米误差验证代理与原壳差异。
2. 在代理上规划头身/腿部分缝线、四肢结构、返口与填充进入路径；先画结构接合关系图，**再**从真实净缝线制作裁片。
3. 对每个拟制版区域，逐一验证网格拓扑、真实 3D↔2D 净缝长度、面片翻转/交叠、布纹方向，以及能否有缝份和实际翻面空间。局部失真过大时增加分片/省道，而不是仅提高宽容度。
4. 按原始约25cm设计的正/侧/背/顶视图核对，确保高密度云绒层最终通过真实覆盖层或工艺近似可制造。
5. 最后逐步接入外耳内片、额云、胸云、灰侧云、尾根、面部刺绣、10 水滴与布带，等待真实面料试片/工厂接口确定，生成正式 1:1 工业图纸。

## 回归与进度口径

运行以下命令重建**草案而不是厂商技术包**：

~~~bash
python scripts/build_stage6_component_register.py \
  --scene experiments/stage6_scene_inventory_20261103/summary.json \
  --seams experiments/stage6_hoof_seams_20261030/summary.json \
  --output /tmp/stage6-component-register-draft.json
~~~

源 SHA 或 42 Mesh 分组改变时，生成器拒绝输出，要求先重新验证真实 Stage 6。唯一进度入口仍是 [PRODUCTION_PROGRESS.json](PRODUCTION_PROGRESS.json)：P2 继续进行中；只有实际纸样、布样、工厂与实物证据取得后才能晋升 P3–P7。初稿中的所有材料、裁片和连接均非正式批准。
