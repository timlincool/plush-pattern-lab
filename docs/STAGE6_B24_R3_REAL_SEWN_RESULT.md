## 最值得继续的工程动作

**下一轮重点已变：** R3下半身曲面真正有改进，但头部依旧像截平圆筒，四腿像管子，不能靠贴云朵掩盖。

1. 保留R3的更好身体成形与940组可证明净缝，但对真实材料边长 P95 **9.934%** 和局部最大**62.66%**做独立负例与可制造性否决，不允许放宽门槛。
2. 优先对照 Stage6 原头颈多环、中央头冠/左右耳根，设计可缝的分体头顶和柔和面部，同时让耳的真实封闭源几何转为有根部连接边的二维布片；不要把整只耳以3D面相交当缝好。
3. 接着考虑面料厚度、适当压力/分腔填棉、自碰撞、可翻面口、真实10cm试布和实物样衣证据，再设计云层作为表面覆件的实际固定方式。五官、水滴最后处理。
4. 强制每轮`source 2D rest + paired netline SHA + actual evaluated Cloth NPZ + front/side/3quarter + shape/sample/strain/contact gate`；任何单一数字改善都不自动升级 P3/P4。
