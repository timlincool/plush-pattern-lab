# Stage 6 四蹄：3D 弧长对位与 2D 缝线投影参考（P0）

此阶段第一次直接从[公开 Stage 6 模型](https://github.com/timlincool/plush-pattern-lab/releases/tag/cloud-alpaca-stage6-visuals-20261028)提取四只蹄与主体的真实开放缝环。它是 **3D → 2D 缝线注册实验**，不是生产纸样。

## 可验证的数学不变量

- 源 `.blend` **89,853,017 字节**、SHA-256 `38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a`；载入前验签，Blender 4.3.2 使用 `--disable-autoexec`。不使用私有仓库。
- 主体四个洞口、四只蹄各有 **512 点有向闭合边界**。沿用现有 `verify_mating_loops` 的最大空间误差 ≤0.0001 mm、同样严格的周长差以及 **反向绕序**，不重采样、不放宽阈值。
- 每一组输出 `body_to_hoof_ring_ordinals`（原拓扑环序号，不是原 Blender 网格 vertex ID），并按相同三维点给出 Q0～Q3 对位标记。
- `arc_length_stations_3d_mm` 按**真实 3D 边长累加**，最终 SVG 中的直线标尺采用该真实弧长坐标。因此它能精确标示缝线长度和对位位置（以导出时数值精度为限）。Q0 的锚点是世界坐标中最高 Z、其次最小 X/Y 的一个**已有顶点**；这不是解剖学的脚掌正面，也不是确定毛向。
- `projected_reference_ring_2d_mm` 是**最小二乘拟合平面投影**。输出三维环与投影环的周长差、最坏局部边长缩短率、离面 RMS/最大值；投影损失不得伪装成布料伸长或被静默抹平。

## 受信环境运行

~~~bash
python scripts/verify_issue14_public_release.py --download-dir local-assets/verified-stage6
blender --disable-autoexec --python-exit-code 1 -b -t 1 \
  --python scripts/export_stage6_hoof_seams.py -- \
  --input local-assets/verified-stage6/cloud-alpaca-stage6.blend \
  --source-sha256 38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a \
  --output local-output/stage6-hoof-seams.json \
  --svg local-output/stage6-hoof-seams.svg
~~~

输出 JSON 包含四蹄对应、拓扑顶点编号、每顶点的真三维弧长、四个 Q 标记和投影失真报告；SVG 使用 **mm 单位 1:1**，提供四幅二维投影参考与四条真实 3D 弧长标尺。**SVG 不提供裁切外轮廓，也没有缝份；不得当作可缝纸样打印裁布。** 输出目标必须事先不存在，避免覆盖历史证据。

主分支可信工作流 `.github/workflows/stage6-hoof-seam-reference.yml` 从公开 Release 匿名下载模型、核验 SHA 后在无凭据 Runner 上只读执行 Blender，保留 7 天 JSON/SVG 小证据，不上传 90MB `.blend`。不在 PR 中执行第三方代码或未经审核的模型。

## 继续开发：真实网格的第一圈相邻面拓扑

从已验证的 Stage 6 四蹄边界，新增只读 `scripts/probe_stage6_seam_band.py`，检查主体四个洞口和四只蹄的**第一圈真实网格面**：

- 对每条 512 点边界的每条边，读取实际相邻多边形，统计三角面/四边面/其他面，识别一张面是否被重复匹配。
- 仅当每条边邻接一张非退化四边面、每个边界顶点有唯一外圈配对顶点、全圈无面重复/外圈合并时，判定 `regular_quad_strip=true`。
- 对规则带输出外圈顶点数与横向边长最小/最大/平均值；不输出模型私有路径或整个坐标数组。
- 对三角面、非流形连接、缝片重合、外圈冲突等明确返回 `quad_strip_failure_reason`，**不自动猜测可缝性、不重采样或补洞**。

可信 `main` 工作流在现有公开模型 SHA-256 与 Blender 4.3.2 校验后执行此步骤，将 `adjacent_face_survey.json` 作为轻量证据保存。这一步仅建立曲面分片的拓扑先验，**尚不计算二维静止裁片、展平应变或缝份**。取得真实调查结果后，再决定采用有切缝的四边形带展开，还是需要三角网格分片重拓扑。

### 实际首圈调查结果与三角环带后续筛选

[可信 Blender 运行 #41078530323](https://github.com/timlincool/plush-pattern-lab/actions/runs/41078530323) 显示：**8 组 512 边界**的直接邻接面**全部是 512 个三角面/组**，每组这些面合计涉及 **768 个顶点**。没有任何一组满足规则四边形带，因此不能把任何模型强制转换成未经证实的 quad-strip 纸样。

下一项小步验证改用**按边界顶点选取的完整第一圈三角面**，统计连通分量、欧拉示性数、边界环数、非流形边与原始 512 点接缝是否完整。如果构成一个连续的双边界三角环带，才考虑添加带切缝的低应变二维展开；若不成立，保留 `candidate_triangular_annulus=false` 并优先定位断裂或重叠面。**该筛选仍不含 2D 裁切线或制造放行。**

### 三角环带的第一项几何展开反例

在 8/8 个连续三角环带通过拓扑门禁后，增加**接缝拟合平面的直接投影**作为基准实验。对每组实际 768 个三角形、768 顶点：

1. 使用内侧 512 个接缝顶点拟合平面；仅做正交投影，**不进行材料参数求解或网格重采样**。
2. 对每条三角面边比较真实 3D 长度与投影后 2D 长度，输出平均/P95/最大相对损失。
3. 记录二维投影退化三角形、三角形正负朝向、面积比例，以及源模型的 3D 退化边/面。
4. 当投影失真不可接受时，保留数值反例，下一轮再考虑切缝、约束展平或分片，**不能将投影直接晋升为裁片**。

这个基准不等于求解最佳展平；它的意义是用真实三角片证据判断：仅靠平面投影会扭曲多少，而不是用原始环长误导制造决策。

### 2026-10-30 实测：接缝平面直接投影不可直接裁切

[可信工作流 #41080431215](https://github.com/timlincool/plush-pattern-lab/actions/runs/41080431215) 已在 Blender 4.3.2、固定模型 SHA-256、禁用自动执行条件下，分析八个真实三角环带。长期结果见 [triangle_band_projection.json](../experiments/stage6_hoof_seams_20261030/triangle_band_projection.json)。

| 环带 | 平均逐边相对缩短 | P95 相对缩短 | 最大相对缩短 |
| --- | ---: | ---: | ---: |
| 主体环 0 | 18.01% | 29.94% | 31.50% |
| 主体环 1 | 16.16% | 27.03% | 28.35% |
| 主体环 2 | 14.01% | 28.61% | 31.25% |
| 主体环 3 | 14.05% | 28.72% | 31.33% |
| 蹄部 base | 14.74% | 25.27% | 26.16% |
| 蹄部 .001 | 12.57% | 25.68% | 29.11% |
| 蹄部 .002 | 16.54% | 28.17% | 29.11% |
| 蹄部 .003 | 12.57% | 25.68% | 29.11% |

8/8 个环带均为 **768 个三角形、两个闭合边界、一个连通分量、Euler=0、非流形边数0**。平面投影的 2D 三角片没有发生面积退化或正负朝向混杂，但**每条边的真实三维长度与二维投影长度失配明显**。以上 P95 是边长相对误差，不等于材料真实主伸长应变，也不能直接套用布料验收阈值。

**工程判定：否决“直接投影并加缝份”的捷径。** 下一步应在这些已明确的三角环带上，选择有切缝/可验证拼接的二维参数化，按三角片计算主伸长与面积/翻面并保留与原始三维缝线的顶点身份，才有资格开始纸样研究。
