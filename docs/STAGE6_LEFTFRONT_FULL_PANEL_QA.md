## 与 LSCM 独立的 3D 曲率检查

在真实 PLY 原三角面上，用 `atan2(||cross||,dot)` 计算各面片顶角，对圆盘内部顶点计算 `K=2π−Σθ`；排除所有切口和外缘顶点。独立离线复核得到：

- 有效内部 17,889 顶点，排除 1,057 个边界顶点。
- 绝对角亏 P95 **2.633°**；正向 `>3°` 的 339 顶点、负向 `<−3°` 的 468 顶点。
- 最大绝对角亏 **189.83°**；强烈局部正负峰值出现在不同曲面部位，不能把该视觉雕刻网格默认视为平滑制造母版。
- 非零内禀角亏从数学上排除整片**精确等长**平面展开；但它**不能**证明需要的具体省道数量、服装布料允许应变、工厂可行的可见拼缝路线。

源码 `validation/intrinsic_curvature_screen.py` 使用原面/源顶点 ID；平面、凸面、鞍面和损坏边界反例均有回归测试。真实曲率数值来自从可信工作流 ZIP 下载的 PLY/逐面明细的独立 NumPy 复核；更新后的 main 工作流需要再次运行来证实新集成字段。
