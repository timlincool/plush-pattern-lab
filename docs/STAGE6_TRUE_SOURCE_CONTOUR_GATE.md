# Stage6 原始三角面真实截面：头身多轮廓与A/B母版偏差门禁（P3）

**P3研究。两次受信main已从原真实Blend/25% PLY SHA重算成功并保存原边交环/XY轮廓的SHA。不是原模型已得到工厂可裁布纸样。**

## 第一性原理：不能只用包围盒把头、肩、装饰突起合成一条缝

[上一轮真实A/B分离头身母版](STAGE6_SPLIT_TORSO_NECK_AB.md)将原主壳每层 `Z±3mm` 范围内的X/Y顶点取1%和99%分位，拟合一个新的64边单环。这是一种**造型草案**，不是源3D网格真正与水平面相交的闭合切缝。若同一高度有多个不相连的截面，这种方法会把本应拆分的部分硬塞进一块头顶盖或后背布片，形式上能配缝，实物上可能明显走形。

本轮直接在**固定SHA原始 Stage6 25% 主壳的真实三角面**求每个 `Z` 平面的边插值交点，每片相交三角形必须产生2个真实源网格边交点；所有源边交点连成度数严格为2的闭合环。对每条环记录原源Vertex ID边对、真实XY、净长度、面积、质心、包围盒与逐环SHA，不把不同环合并，也不假造“原主壳已经可展平”。

## 已经两次受信main重算的真实原源网格结果

| 固定原主壳切片Z(mm) | 真实独立闭合环数 | 制造研究影响 |
| --- | ---: | --- |
| 60、100、115 | 1 | 可研究主躯干连续截面变化 |
| **125** | **2** | 主体外另有后侧小闭合轮廓，不可一条环包住全部 |
| 130、135、140、145、155、180、205 | 1 | 可测主要轮廓源边与造型 |
| **230** | **3** | 头顶部中央主环外，左右各有分离的侧面突出环 |
| **245** | **2** | 高处仅保留左右小环；原中间中央头部截面已消失 |

其中 Z=230mm 真实中央环周长约153.09mm，两侧分离环周长约45.52/45.51mm。**这些侧突出环在原主壳上的视觉工艺归属仍未确认**；不能在无证据下称它们一定是耳朵或云团，也不能自动把它们删除。

当前A/B分体头颈研究盖片在Z230mm都只设计**一条**源包络拟合环，其二维环周长约319.8mm，明显不同于原真实中央环的153.1mm，也没有解释两条侧环。直接对源真实主环与试样环取**二维轮廓Hausdorff距离**：预审在Z230约38.21mm；A在Z145约25.55mm、B约28.87mm；不能靠“样纸16段数字长度相等”证明外观正确。

**注意Hausdorff仍是同高度XY平面上的轮廓差距，不是立体布料回弹或成品相机投影差值。** 一切布料/填棉/外观签核仍需实际试样。

## 新的工程门禁

- `validation/stage6_true_source_contours.py`：真实三角面与水平面交线，保留原源Vertex ID边对，拒绝开环、叉路、非流形/零面积和恰好压中源顶点的不稳定截面，不从包围盒凭空生成轮廓。
- `validation/stage6_source_contour_vs_trial.py`：真实逐环与同次A/B母版在Z135、145、155、180、205、230的同高度轮廓逐层比较，记录源的**额外环数**、源/试样周长、XY Hausdorff距离与多轮廓告警，并生成**固定公共XY比例的13截面SVG研究图**。
- `scripts/audit_stage6_true_source_sections.py`：只读固定SHA公开原Blend生成的25% PLY、同次A/B JSON、拒绝覆盖研究证据；分别输出原环逐源边明细、可审计摘要、SVG及SHA。
- 受信 Stage6 main-only Actions：在既有真实模型和A/B两方案生成后做完整原三角面截面审计，强制核验Z125=2、Z230=3、Z245=2；若原形状或输入版本发生变化，**拒绝**将此前母版结论自动沿用，不提交工业裁切文件。

## 下一步为何要优先修正头顶工艺

A比B更适合先做便宜废布小样的结论**不因此升级为正式制版选择**。首先需要从原Stage6真实3D将Z230左右侧突出区域与中间头顶的装配/隐藏缝区分，核对真正耳根/云团与头顶的分界；重新设计单独的头顶小片/侧突出片接口，避免让一块过大的试验顶盖强行承担全部几何。其次应对真实Z125的独立后侧截面设立结构风险，不应继续使用单环连续包围盒。
