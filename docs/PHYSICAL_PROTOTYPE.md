# 从数字研究到第一件真实试缝样品

2026-10-26 增加 **1:1 纸质裁片试缝包**，目标不是在视觉上再渲染得更像，而是让当前合成椭球纸样可实际打印、裁出 12 个侧片和 2 个帽片，完成第一次廉价实体试验。

## 先说明边界

**此功能只生成“试布样品制作资料”，不代表能直接做出用户原始角色玩偶、可量产或满足儿童玩具安全法规。** 当前 12 片双帽片模型在 Blender 4.3.2 48 帧下仍有非邻接三角面穿插，接触门禁拒绝；实际面料、填充弹性、洗涤与缝线强度尚未测。

专业流程需要裁片缝线、缝份、对位缺口、布纹毛向、原尺寸打印与实体试缝记录。参考 Mori/Igarashi (ACM TOG 2007，DOI 10.1145/1276377.1276433) 与 Jin 等 ToyAssembler (CAD 2022，DOI 10.1016/j.cad.2022.103356)：数字模拟必须与缝后实物回测，而非认为几何研究通过就足够。

## 立即可运行的第一版

在可信 Python 3.11+ 环境、仓库根目录执行：

~~~bash
python -m pip install --only-binary=:all: -r requirements-dev.txt
python -m pip install --no-deps --no-build-isolation -e .
python scripts/capped_gore_pattern.py --panels 12 --pole-cut-deg 8 --out /tmp/prototype-input.json
python scripts/build_prototype_kit.py --input /tmp/prototype-input.json --output-dir /tmp/plush-toile-kit --paper A4
~~~

或将 --paper A4 改为 Letter。输出目录必须事先不存在，以防覆盖研究历史。

输出为 manifest.json、sewing-guide.md 与若干张 sheet-NN.svg，每张 SVG 的 width/height 与 viewBox 直接对应纸张毫米，**没有压缩到页面的缩放命令**。必须设置打印机 100% / actual size，检查每页 **10×10 mm** 校准方框；若尺寸错误，禁止裁布。

## 裁片内容

- 侧片 P01…P12 各一件，帽片 UPPER/LOWER 各一件：不是只画“代表性一片”。
- 每片都有黑色裁切外轮廓、蓝色缝线（默认暂定 6mm 缝份）、红色对应缝线标记；实际标记在缝线上转描，不要直接把红点当作裁开布片的深缺口。
- 侧片具有绿色箭头表示**毛向候选假设**，非已采样面料的确定经纬；将 12 个侧片统一朝向。
- P12.right 与 P01.left 的侧缝在 40%～60% 弧长位置留出**返口**，紫色空心点标记开口的两个端点。缝完其余片和两个帽片，经返口翻面、少量填充，再手缝封口。
- 算法独立复核了相邻侧缝长度、帽片到侧片横向端缝逐段长度与裁切轮廓容纳净缝线；若不匹配或单页放不下，会明确拒绝输出，不偷偷缩放。

## 下一次要从实物采集的数据

完整记录：打印方框的实测尺寸、原料类型与批次、裁片编号和用时、试缝线与缝份、对位偏差、实物高度/宽度、顶部帽片鼓包、褶皱位置、填充重量和弹性回复，以及前/侧/后/顶各一张实物照片。没有这些输入，AI 无法可信地把纸样从“几何可运行”晋升为“能做出预期外观”。

输出不会自动上传照片或材料数据；本功能没有网络请求、Blender 脚本执行或私人文件读取。图片/原始私人模型不能因此自动公开。
