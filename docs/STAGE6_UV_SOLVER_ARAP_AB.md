# Stage 6 真实主壳 B 三片：LSCM / ARAP 与统一尺度诊断

**P3 研究，不是正式工业纸样或材料力学模拟。原 PLY、真实三维拼缝、四蹄接口、三角面来源及裁片布局不修改。**

## 为什么必须区分尺度与真实形变

原始稀疏 LSCM 用两点固定零位/水平长度求解，其中水平长度选用了沿网格的3D切缝总长；这不是3D端点欧氏弦长。真实Stage6左前原切缝长40.8921mm，端点弦长34.8977mm，二者相差约17.2%（路径长/弦长−1）。这项约束有可能影响UV尺度，但**不能**据此单独解释全部二维失真。

对每片每个来源无向三角边，根据真实 3D 长度 `l3` 与二维长度 `l2` 求**仅用于数值诊断**的最优统一尺度 `s=Σ(l2*l3)/Σ(l2²)`；然后分别报告原始P95和统一缩放后的相对边长误差P95。此优化不移动任何原始3D边、不改变UV拓扑或自交，不可以当作真实工厂校准或松弛3D缝线。

## 对照方法与来源

- 来源：公共 Stage6 可编辑 Blend SHA-256 `38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a`；25% PLY SHA-256 `5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd`。
- 来源的三盘裁片、逐面原 Face ID/Vertex ID、原始 LSCM UV/两侧径向缝线必须来自**同一次可信 Stage6 Runner**，两份 JSON 用 SHA-256 互相校验，不能从别的旧模型冒充。
- 方法一：保留上一轮原始两点 LSCM，作为完全冻结的失败基线。
- 方法二：ARAP(local/global、面积加权真实三角形内禀梯度)；**固定两端点实际3D欧氏弦长**，而不是按切缝路径总长伪造直线距离。分别以源3D PCA 投影与已有 LSCM 坐标作为初值。限定每片30轮，真实3D原顶点无修改。
- 对每片、每种方案独立评估原3D/候选2D三角边长误差、统一尺度诊断、UV翻面、近零面、全局非零面积重叠及跨片同源原3D径向缝线的两侧 UV 周长差。所有输出均为带来源映射的研究 JSON，绝不自动产生 P4 SVG/DXF 裁片。

## 负例与下一步

- 开口圆柱（真可展曲面）的独立正例必须接近等距且无UV重叠；无边界洞口/错误来源/不合法迭代预算/非有限顶点/整体UV坍塌均拒绝或禁止制造。
- 如果真实ARAP也在多个子片出现UV重叠、翻面或两侧缝线不同长，**继续否决**，不采用“最小错误数字”自动选算法。下一步需要全边界可逆性约束、设计图标注可见缝、物理能接受的省道与返口工艺方案。
- 2D算法不代替面料经纬伸长、毛向、翻面、填充、实样、两处四线交汇处理和工厂认可；**P3继续、P4未开始**。
