# 云朵羊驼 25 cm｜单只实物加工优先方案（候选技术包 v0）

> 状态：**供应商询价与纸样收口需求**，不是工厂已经接受的裁片文件，也不是可以直接裁床开工的承诺。目标：只制作**一只**，一次性交付，工坊尽量不承担完整原创研发。

## 一、冻结本轮商业需求

- 件数：1只原创羊驼，约25cm（含耳朵/绒高的测量基准待图上确定）；**不默认有后续批量订单**。
- 保留设计要素：两耳、四腿/蹄、主要云朵覆层、尾巴、刺绣面部、**10枚**软布水滴及短而牢固的布带；外层建议使用合成羊羔绒/短毛绒，填充为聚酯纤维，不用动物来源材料。
- 服务：让工坊**按提供的生产文件核对、采购现货料、裁剪、缝制、刺绣、分区填棉、整形、拍照、寄出**。若纸样存在无法执行的缺口，应在接单开工前提出一次性疑问清单，禁止擅自放缩版型或省略部件。
- 交付模式：委托方不安排“制作→寄回→再修改→返工”的往返循环；工坊可做内部自检/整形，但**不能保证未经实物调整的首次成品与3D原图1:1相同**。客户批准后的图纸版本、颜色和材料替代必须记录。
- 谈价参考：单只订单希望先询 **¥600–1,000 含料、人工、刺绣、填棉、配件**；预算弹性约¥1,500（**仅谈判目标、不是实测供应商承诺价格**），运费、税费、打版费、样品费必须逐项列明。

## 三、我方在工厂报价前能提前完成的工作

- [ ] 冻结约25cm外观：正面、背面、左/右侧、45°和顶部，注明耳尖与云毛的计量基准、关键比例、必须保留的10水滴。
- [ ] 对比旧26页纸样与当前原3D外观，决定**简化的工业分片**；尤其头身、耳根、四蹄及云覆层，优先可缝和完整，而非追求三角网格数值到零。
- [ ] 输出完整单套、1:1的 PDF/SVG/按工坊接口DXF；含**净缝线和裁切线两条独立线**、缝份（初始建议主壳6mm、水滴4mm，最终依厂方工艺确认）、镜像/数量、毛向、对位、返口及拼缝表。
- [ ] 重新设计 **10枚**水滴的正反片与10条短布带，确定挂点、连接路径、颜色与牢度验收；不继续沿用旧8枚挂点表。
- [ ] BOM 与面料要求：提供白/浅灰羊羔绒、短毛绒、灰蹄面料、耳芯、刺绣线、聚酯填充、稳定衬的**候选材料规格**。厂商提供真实可采购料号/色卡并在开工前确认；不把历史150g备料或104.5g填棉初值当作已验证定量。
- [ ] 出头部刺绣定位图、分区填棉顺序/建议初值、装配SOP、成品照片视角及尺寸检验表。
- [ ] 纸样打印校准（100%比例+50mm标尺）、闭合/净缝配对/件数和重复版号程序核验；不以Blender弹簧缝隙替代机缝与可翻面验证。
- [ ] 整包manifest（各文件SHA、版本、不可混用提示），由委托方核准后交工坊。

## 四、真正需要厂方确认的最小边界

1. 是否愿意接**单只**、只负责执行工艺？能否按客户提供A4实尺PDF/SVG或指定DXF版型施工？不能的地方是哪些？
2. 接收面料/辅料的可采购选项、具体颜色和绒长，是否可用替代料？替代需要事先确认。
3. 工坊为完成单只需要的**额外纸样修订工作**到底有多少？必须在接单前说明，单列费用，不默认允许无限改版。
4. 报含料、裁剪、刺绣、缝制、填棉、附件、照片、包装、运费、税的**固定总价和交期**。不能只报“批量单价”或“打样费”。
5. 一次验图机制：工坊先指出明显不能执行的缝边、无法翻面/填棉和牢度问题；委托方修好或书面同意替代后一次施工，不进入多轮来回寄样。
6. 纸样及原创设计归属委托方；请确认是否需要授权公开工坊拍摄成品照片（默认不授权外部公开）。

## 五、明确的工业放行门禁

**当前仅具备询价材料，不具备“可直接按版开工”的已验证生产包。**

单只试制文件可交厂前需至少：完整统一的最新版1:1裁片、10枚水滴与装配表、真实面料方向、刺绣位置、返口/缝份/件数、分区填充、来源和版本审计。供应商必须确认自己能按文件执行。

厂方首次加工实物后仍存在面料弹性、填充量、站姿、手感与附件牢度的不确定性。没有样品/实际强度证据时不能称量产定版、100%相同或儿童玩具安全合格。

**本项目执行优先级调整为：单只完整纸样→询价与厂家可加工性确认→一次制作交付→实物评价；R7以后局部自碰等研究只处理会阻碍打样的关键问题。**
