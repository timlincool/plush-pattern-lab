# 裁片数量不是越多越好：几何应变 vs 缝制成本

这是**合成椭球体**的可重复实验，不代表真实羊驼或实际面料的允许伸长率。

```bash
python scripts/gore_tradeoff.py --study-threshold 0.10 --output output/panel-counts.json
```

| 裁片数 | 最坏局部几何伸长偏差 | 缝制关系总长 | 含暂定缝份的裁片总面积 |
|---:|---:|---:|---:|
| 6 | 19.36% | 1182mm | 58,310mm² |
| 8 | 12.85% | 1576mm | 63,993mm² |
| 10 | 9.64% | 1970mm | 69,276mm² |
| 12 | 7.72% | 2364mm | 74,406mm² |
| 14 | 6.44% | 2759mm | 79,466mm² |
| 16 | 5.53% | 3153mm | 84,488mm² |

相同轴对称造型与假设条件下，增加裁片可以降低几何畸变，但让接缝增加、裁切净空及缝份面积增大。脚本选择满足**研究用10%几何门槛**的最少片数（默认为10）；不会把这个门槛误称为真实布料的安全伸长率。

制版专业人士下一步会利用**真实样布的经纬加载曲线、毛向、切片形状、公差和绣花强度**建立单位一致的可生产判定，而不是只靠这张单项几何表。
