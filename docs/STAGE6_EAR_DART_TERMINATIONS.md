# Stage6 耳根 A 内侧短弧：从两个开放端点到原始三角网格终止点（P3）

**状态：2026-11-11 已由两次受信 main Stage6 Blender 4.3.2 实跑，源路径、41Mesh审计与原始研究SVG/上游资料五个文件逐字节SHA相同；主干Python CI通过599项。仍非耳根真实缝合净线或工厂纸样。**

## 原问题与选择

前一轮 [16条真实耳根源短弧审查](STAGE6_EAR_ROOT_QUADRANT_ARC_SCREEN.md)发现：A Z230 内侧弧左8.926792mm、右8.418306mm，在41个真实产品 Mesh 的正/背/对应侧方向近原主壳第一表面数量低。但每弧仍有两个开放端点；单纯“有云团遮挡”不能变成可缝分片。

本轮不复制过去失败的单片大头盖，也不修改四个512源蹄口。直接用原公开 Stage6 25% PLY 的 **59,306个原源顶点、116,568个三角面、175,876条唯一原网格边**，从两端原三角面与Z230交线上的真实插值点出发。原先点不是原顶点，因此先重算与真实源边交点，再进入对应的低于Z230的原始顶点，不能凭虚拟坐标跳边。

预先指定两个“省道终止点”研究高度：**目标Z225与Z219**，分别在每侧接缝两端平均XY附近固定12mm X/15mm Y窗口、Z目标−3至230mm内选择最近原网格顶点。每对原连接臂先用真实原边Dijkstra最短路求初稿，再测试是否提前合并；如果出现两臂在预定终点前占同一顶点，则禁止其共享路段，重算第二臂并要求除终点外不共享任一原顶点。原始面、源路径、端点Vertex ID与完全确定的SHA全保留。

## 严格来源与否决条件

- 原Blend SHA固定：38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a，25% PLY SHA固定：5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd。
- 输入必须是**同一次**固定来源的A/B闭环源JSON、完整41产品Mesh五视角审计JSON及16条原弧JSON。核对原Source边对、XY插值、闭环SHA与完整弧长；篡改一处原边/位置或跨运行报告即拒绝。
- 源网格所有三角面和原四个512蹄口均保持不变；仅写真实路径Vertex ID、3D XYZ、两臂路径长度、绕开提前合并所需额外长度、收口附近离散几何间距及研究SVG。
- 受信main Blender 4.3.2对每个实际原源路径抽样、以原完整41个产品Mesh做正/背/左/右/顶首表面与3mm独立网格邻近筛查；原423个毛发/曲线和渲染修改器均不作为已测试工艺。
- **禁止推断数学上闭合的3D路径就是实际可裁布片**。目前没有把原三角曲面真的切开并生成两侧净缝映射，也没有验证布料伸长、真实缝份、反面翻出、填充和厂商裁切。即使两条路径在3D可分，也可能极窄或与设计图、云团/耳实际装配冲突。


## 两次独立受信原 Stage6 Blender 的最终证据

[Stage6 #42971171926](https://github.com/timlincool/plush-pattern-lab/actions/runs/42971171926) 与 [Stage6 #42971362151](https://github.com/timlincool/plush-pattern-lab/actions/runs/42971362151) 已成功完成实际原Blend/PLY和41产品Mesh对照。两次所得**源路径JSON、路径SVG、41Mesh原始首命中JSON、上一轮A/B源环JSON及四象限来源JSON五个原始文件的SHA-256全部相同**，完整Action ZIP哈希不同，不混淆二者。Run/Commit/Artifact ID、原文件哈希、4条真实路由测量/顶点ID及五视角数据已永久归档：[原Stage6双重证据](../experiments/stage6_ear_dart_termination_20261111/summary.json)。[Python CI #42971362108](https://github.com/timlincool/plush-pattern-lab/actions/runs/42971362108) 599/599项通过。

首次完成**两条真正原Source Mesh边路径仅在一个预定tip汇合**的可复现构造，但其**不会产生两条已匹配的静止二维缝线**。最重要的否决反例仍然是左侧：未经拓扑门禁会提前合并7/14个源顶点；强制绕行后距终点4mm外原源顶点最小间距只有1.639mm/0.845mm，是明显值得拒绝的窄根研究候选。此距离是离散原源顶点筛选，不是连续布料缝份净宽。

新41Mesh审查补充：左侧Z225/Z219研究接合路径的第二臂，顶视均有2个源顶点样本近原主壳；右侧Z225第一臂顶视8/16、对应侧1/16，降到Z219第一臂顶视仍8/16、对应侧增至4/16，第二臂对应侧7/16。**降低终止高度未稳定改善右侧可见性，不能用单一数学路线或左右镜像直接制版**。所有结果仅原41个视觉Mesh表面，原423个毛发曲线、实际材料与设计/工艺签核仍不在通过范围。

**下一工程决策：先以现有失败结果否决“直接延长两条内侧短弧到一个省道尖”的工艺捷径**。若要继续成品开发，应转换为真实局部耳根根片/小过渡片与独立云/耳覆盖的接合方案：在原3D主壳选取实际成对的切边，证明两边源净线和2D无重叠/可接受应变，按面料厚度与6mm研究缝份验证真实翻面、填充、缝合顺序，最终与四视图设计及废布实物对照；不再以提高遮挡率来宣称生产可行。
