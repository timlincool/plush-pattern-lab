# Stage6 耳根 A 内侧短弧：从两个开放端点到原始三角网格终止点（P3）

**状态：锁定真实 Stage6 25% 主壳代理，本地已实际运行；受信 main 完整 Python/Blender 4.3.2 验证待完成。不是已审批的耳根省道、缝合双侧净线或工厂纸样。**

## 原问题与选择

前一轮 [16条真实耳根源短弧审查](STAGE6_EAR_ROOT_QUADRANT_ARC_SCREEN.md)发现：A Z230 内侧弧左8.926792mm、右8.418306mm，在41个真实产品 Mesh 的正/背/对应侧方向近原主壳第一表面数量低。但每弧仍有两个开放端点；单纯“有云团遮挡”不能变成可缝分片。

本轮不复制过去失败的单片大头盖，也不修改四个512源蹄口。直接用原公开 Stage6 25% PLY 的 **59,306个原源顶点、116,568个三角面、175,876条唯一原网格边**，从两端原三角面与Z230交线上的真实插值点出发。原先点不是原顶点，因此先重算与真实源边交点，再进入对应的低于Z230的原始顶点，不能凭虚拟坐标跳边。

预先指定两个“省道终止点”研究高度：**目标Z225与Z219**，分别在每侧接缝两端平均XY附近固定12mm X/15mm Y窗口、Z目标−3至230mm内选择最近原网格顶点。每对原连接臂先用真实原边Dijkstra最短路求初稿，再测试是否提前合并；如果出现两臂在预定终点前占同一顶点，则禁止其共享路段，重算第二臂并要求除终点外不共享任一原顶点。原始面、源路径、端点Vertex ID与完全确定的SHA全保留。

## 严格来源与否决条件

- 原Blend SHA固定：38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a，25% PLY SHA固定：5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd。
- 输入必须是**同一次**固定来源的A/B闭环源JSON、完整41产品Mesh五视角审计JSON及16条原弧JSON。核对原Source边对、XY插值、闭环SHA与完整弧长；篡改一处原边/位置或跨运行报告即拒绝。
- 源网格所有三角面和原四个512蹄口均保持不变；仅写真实路径Vertex ID、3D XYZ、两臂路径长度、绕开提前合并所需额外长度、收口附近离散几何间距及研究SVG。
- 受信main Blender 4.3.2对每个实际原源路径抽样、以原完整41个产品Mesh做正/背/左/右/顶首表面与3mm独立网格邻近筛查；原423个毛发/曲线和渲染修改器均不作为已测试工艺。
- **禁止推断数学上闭合的3D路径就是实际可裁布片**。目前没有把原三角曲面真的切开并生成两侧净缝映射，也没有验证布料伸长、真实缝份、反面翻出、填充和厂商裁切。即使两条路径在3D可分，也可能极窄或与设计图、云团/耳实际装配冲突。
