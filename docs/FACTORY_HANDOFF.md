# 工厂交付与验收清单（Factory Handoff v0）

**用途**：围绕约 25 cm 原创云朵羊驼生成**一个工厂能据此报价、打样、修版和批量复现**的正式技术包。不代表当前任何项目文件已通过。实际进展以 [PRODUCTION_PROGRESS.json](PRODUCTION_PROGRESS.json) 为准。

## A. 给工厂询价前（可以现在开始）

| 必须确认 | 目标 | 当前 |
|---|---|---|
| 外观图片、目标高度、颜色、关键零件 | 厂商能理解产品，提供初步打样 / MOQ / 单价范围 | **部分就绪**：原图、D 造型、约25cm |
| 真实尺寸/各视图 | 头/身、四足、耳、云朵、尾巴、水滴与站姿的尺寸/公差 | **待冻结** |
| 面料备选与非动物材料要求 | 绒长、底布经纬弹性、毛向、厚度、填充 | **材料方向已定，实际布料未定** |
| 工厂支持的图纸/绣花格式 | 是否接收矢量 PDF、SVG、DXF（版本、单位、layer、polyline）、AI/PSD、DST/EMB/特定机器格式 | **需工厂书面确认** |
| 开模/打版、首样/修改费用、MOQ、版型权利 | 不同厂商的费用和交付责任可以比较 | **需工厂报价** |

> 工厂采用的 CAD / 刺绣 / 排料设备各异，**不要把“支持 DXF”推断为支持任意版本和单位**。在获得回复前只交付中立矢量研究文档和厂商问题清单。

## B. 正式打样技术包（P5 Gate）

统一包名建议 `cloud-alpaca_25cm_factory-v1`，在版本 `manifest.json` 固定文件哈希和版本号，并在文件名中标注尺寸单位 mm。

| 文件夹 | 目标内容 | 校验规则 |
|---|---|---|
| `01-appearance/` | 正、侧、背、顶四视图，设计参考、选中外观、颜色图、关键尺寸与公差 | 四视图与 3D 比例一致；尺寸可量测；签核版号 |
| `02-patterns/` | **真实角色每一片** 1:1 净缝线、裁切线、缝份、返口、镜像与件数、经纬/毛向、对位、拼片关系图 | 10×10 mm 或厂商尺寸标尺实测通过，严格逐段对应缝长；不能偷缩放 |
| `03-embroidery-and-details/` | 眼/鼻/嘴定位、绣线与颜色、各水滴结构/尺寸/缝线、短布片连接、耳根/尾根细节 | 从真实头部裁片映射五官；绣花机文件须由指定厂商或设备软件验证 |
| `04-materials-bom/` | 每个部件的材料代码、色卡、样卡、用量、纹理方向、绒长、基布克重/拉伸/厚度、填充 | 不把 Blender Hair BSDF 或合成样例直接当采购规格 |
| `05-assembly/` | 生产工序、缝制顺序、翻面、填棉重量/局部比例、隐藏接缝与封口说明 | 不存在“有表面相交就当作可缝”隐含逻辑；工厂首样可实际操作 |
| `06-qc-and-revision/` | 验收尺寸、四视图差异、颜色/手感、附件牢度、异常记录、修版表、材料与纸样版号 | 每次修改都有问题编号、照片与修改内容；不能以渲染代替实物 |
| `manifest.json` | 产品/尺寸/版本、源 SHA、每个文件 SHA-256、状态 `draft/sampling/approved` | `approved` 只能在有标准样品与工厂共同确认后设置 |

## C. 实物验收（P6 Gate）

需要由实际样品证明，不可自动生成：
- 真实样布经/纬向拉伸与回弹、厚度/绒毛方向、色差和可采购性；样布编号与批次。
- 实物四视图照片（固定角度/相机与尺寸尺）、实际高宽深、脸部绣花位置、站姿、云团鼓胀、尾巴、耳根与全部水滴连接的差异。
- 实物裁片编号/实用缝份、缝制工时、返口与填棉量、褶皱、修版的最终数值。
- 交叉/自碰、附件拉力、适用的安全/标签/洗涤标准：根据产品是否面向儿童及目标销售市场由厂商与专业机构确认，软件不替代检测。

## D. 量产锁版（P7 Gate）

最终必须同时具备：**签核四视图 + 厂商接收的最终纸样 + BOM 实际料号/色卡 + 缝制/填充工艺 + QC 公差 + 实物 Golden Sample + 目标市场合规证据**。缺任何一项，不得标记量产就绪。

## E. 现有真实与合成资产的边界

- [四张参考图与 D 外观](../design/reference-v25/images/README.md)：**设计输入**，非生产四视图定稿。
- [Stage 6 公开 Blender](https://github.com/timlincool/plush-pattern-lab/releases/tag/cloud-alpaca-stage6-visuals-20261028)：**3D 可编辑场景**，不是纸样。
- [四蹄接缝与 8 组局部展平](STAGE6_SLIT_UNROLL.md)：**几何研究**，不包含完整裁切外轮廓。
- [12片+2帽片合成椭球试布](PHYSICAL_PROTOTYPE.md)：**打版引擎的合成演示**，严禁冒充此角色的裁片。
- **尚无实物样品、真实材料力学参数、厂商确认的机器接口和已审批量产纸样**。

## F. 厂商沟通最少要问的问题

一次沟通确认六件事：`样品与版费`、`免费修版次数/周期`、`接收的纸样/刺绣格式及其确切版本`、`可选面料样卡与填棉`、`MOQ/分档单价/交期`、`纸样与知识产权归属`。然后把答案记录到 `docs/PRODUCTION_PROGRESS.json` 的 P1 证据与阻塞项，不能凭猜测填写。
