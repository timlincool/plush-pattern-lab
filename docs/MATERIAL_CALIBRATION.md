# 合成面料与填充的实测数据规范（待引入真实样布）

模仿专业毛绒设计工作流，先测而非先猜布料弹性。初期仅支持**输入契约和验证**，尚无授权可发布的真实试布测量值，不能宣称已经标定。

## 每一种布料的最低数据

- `material_id`、布料供应批次、底布构造、毛长/毛向、面密度 g/m²、厚度 mm
- `warp` 和 `weft` 两组试布，标定长度/宽度(mm)，拉伸力 N 与长度 mm 的逐点记录
- 试验速率、温湿度、预载、重复次数、加载/卸载曲线和恢复时间
- 缝合样品的相同材料与针距，填料类型、填充质量 g、压缩载荷 N 和形变 mm
- 刺绣/贴片区域的独立增刚系数或对应独立布料试样

**实物数据缺席时，参数必须标记 `ASSUMED`；不可把 Blender 内部弹簧/气压设置换算成真实聚酯棉性能。**
