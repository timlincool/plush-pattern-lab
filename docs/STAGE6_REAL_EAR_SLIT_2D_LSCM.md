# Stage6 原始耳根3D环带：侧开缝成为二维单片与源净缝不匹配实测（P3）

**2026-11-12：固定公开 Stage6 25% 原源三角面、两次已受信一致的非水平N15/N17真实3D根片，已本地实跑12种展平方案；完整主分支 Python/Stage6 CI待复核。研究性2D参数化，不是物理材料静止纸样、不能送厂裁布。**

## 为什么必须真实裁开原源环面？

[上轮原始非水平根片](STAGE6_NONHORIZONTAL_EAR_ROOT_3D_RESEARCH.md)已经有逐段严格匹配的主体↔过渡片↔上方耳壳3D源边（世界XYZ、原Vertex ID/Face ID、相反绕向）。N15/N17源三角面上下缝之间的最短边图路径16.33–19.48mm，优于被否决的5mm水平根带，但**上缘耳状壳XY最窄仍仅6.1–6.7mm**。这是3D必要条件，不说明2D布片能不变形缝回去。

本轮完全使用已验证原研究的真实派生root patch三角形（N15左右1680/1755面，N17左右1865/1940面）与原Source边ID。固定在每片3D环面内依次测试**内侧（medial）、后侧（posterior）、外侧（lateral）**三条研究切线，4片×3方向共**12组**，不依赖LSCM解好看与否筛选方向。

1. 从每片原上下源边闭环选定极值锚点，沿**真实3D三角网格的内部边**求最短路，禁止中间穿越另一个边界点。
2. 真正将沿路的顶点身份按两侧triangle face fan拆开；物理XYZ与每片原Face ID不改。严格要求由Euler=0、两个闭合边界的原环面变为**Euler=1、一个闭合边界的三角圆盘**，新原源cut的两份边界段对每条源边一一对应且绕向相反。
3. 对每片真实圆盘用稀疏Least Squares Conformal Maps（LSCM）求一组自由边界二维参数化，固定两个原3D点解除相似变换自由度。**必须先记录全局单一等比尺度校正（最小二乘全边相对长度）**，再计算2D三角边长相对于原3D的相对误差；否则LSCM任意尺度会被误判成布料拉伸。
4. 对所有二维三角面做有向面积/翻转检查，用Shapely STRtree计算**正面积三角面交叠**（不是只看包络盒）；按原cut source边段身份及二维边界方向，一一配对两侧二维净缝长度，不把重复Source顶点误拼成一条虚假线。
5. 单独检查二维上下源边**采样顶点最近距离**是否小于双6mm研究缝份。这只是一项点样本预筛，非连续布料有效宽度或可出纸样的缝份几何。

### 技术边界与下一步

这轮的二维坐标是**自同一固定3D源网格求出的研究参数化**，不是仿布料或经纬/绒向校准的自然静止尺寸。没有上胶、厚度、折边、缝份真实裁线、内外耳/云团实际结构、返口及填棉或实体试样。10% P95与3% 2D净缝差是**研究预警**，不是厂家工业容差。

可信 main 工作流需检查全部12个方案的源Face ID保存、3D精确source边重复、拓扑、相似尺度、反例、交叠面积及SHA，完整JSON会包含所有研究二维顶点和三角面，SVG只是平面检查图。无论软件CI如何，不能将这12项研究标为P4裁布批准。

下一实务路线应避免让长度不一致的两条LSCM边强行上机缝；要么在源3D几何与独立耳云层的真实装配中修改分片线及分片拓扑，要么使用**面料样卡实测的各向异性伸长和缝制回弹**建立有约束的2D净缝匹配优化，并用真实布样验证。不能单纯让LSCM“指标好看”就通过。
