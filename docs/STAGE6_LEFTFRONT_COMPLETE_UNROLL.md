# Stage6 左前完整区域：真实径向切缝与 LSCM 二维展开研究

**当前为 P3 实验，不是 P4 裁布纸样。** 原始来源是公开 Stage6 SHA 固定的 .blend、25% 低面数代理及已经验证的 Y=20mm 四区域分区。任何真实模型 UV 失败都必须保存。

## 真实目标及边界

左前主壳有 36,833 个三角面、18,913 个顶点、512 条来源蹄口边与约 481 条区域外缘边。原有两条闭合边界环（Euler=0），不能在不增加切缝的情况下作为单片简单平面裁片。

1. 使用确切 SHA 的同仓库 25% PLY，按真实 3D 面心挑出全部 36,833 面，保持源面和源顶点 ID。
2. SciPy Dijkstra 仅沿主壳内部网格边选一条最短的从蹄口到外缘的径向切缝；不能穿越其它来源边界。
3. 按真实顶点的相邻面扇复制切缝两侧顶点。独立验证切开后是单连通、一个闭合边界环、Euler=1 的拓扑圆盘；原始 3D 几何不变。
4. 基于原始 3D 三角面的局部测地长度/面积构造稀疏 LSCM（Cauchy–Riemann least squares），固定径向切缝的两端与原始切缝 3D 长度，限制求解预算。
5. 对所有原始三角面计算 3D/2D 边长误差、二维面积翻转、近零面积、二维布料到 3D 的几何主伸长；Shapely STRtree 检测非零面积重叠。
6. 分类并逐段记录来源蹄口净缝、其它布片配缝和新径向切缝两侧的 3D/2D 边长。真实 UV 详细数据保留原面、源顶点和展开顶点映射。

## 工程验收与拒绝

可展开圆柱面正例要求接近等长、无翻面和重叠；丢失面片、重复索引、损坏蹄口等反例必须拒绝。真实羊驼较强三维曲率可能使单切缝 LSCM 出现严重边长失真/UV 折叠；出现时**保留完整失败指标，不通过放宽阈值冒充生产完成**。

研究误差触发线8%不是工厂的面料伸长公差。SVG虽然以 mm 标注，**NOT A CUTTING TEMPLATE**，不能直接交裁床；尚无真实面料、毛向、返口、缝份及厂家设备校准。

## 可信实验与下一步

从受信任 main 工作流依次验 Stage6 源 SHA、Blender 4.3.2 四蹄配对、重建25%代理与BVH、四区3D拼缝，最后执行 scripts/unroll_stage6_leftfront.py。输出简要JSON、保留原始网格索引的UV详细JSON和研究SVG。

如果真实完整区域失败，应当选择更合理的**额外纵向缝/省道/分区方案**，由原始外观图确定可见缝线位置，随后再为其余三区建立可缝的二维净缝线；下一次必须同步更新 docs/PRODUCTION_PROGRESS.json。
