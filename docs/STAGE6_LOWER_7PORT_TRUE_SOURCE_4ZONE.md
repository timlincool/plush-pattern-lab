本轮复用已核验的 original 25% Stage6 PLY，SHA256 `5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd`，原公开Blend SHA `38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a`。同轮原三头帽 `source_three_caps.json` 和 `four_region_seam_graph.json` SHA相互绑定，绝不使用合成椭球、单层BBox或旧24片替代。
