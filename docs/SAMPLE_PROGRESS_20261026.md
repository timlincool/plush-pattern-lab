## 可看到的真实模型是什么

`scripts/render_synthetic_evidence.py` 现在读取**同一实验**保存的 `.blend`、数值报告和接触审计，严格核对文件哈希、顶点数、面数、完整的有限非缝线见证；新建相机与灯光渲染三种 PNG：

- `three_quarter.png`：合成椭球的三分之四视角，侧片用浅蓝绿色区分，上/下帽片另色；
- `side.png`：另一侧便于观察拼片；
- `lower_join.png`：红色标识命中非缝线相交的**网格面片**，不是修复结果，不是精确交点。

自碰撞开/关两类都由 `.github/workflows/selfcollision-ab.yml` 在**可信 main** 触发，PNG 连同数值证据作为 Artifact 保存。**渲染不会修改或重新保存原来的 .blend 网格，不会调用私有设计图。** 视图不得冒充实体样品、用户原设计或安全合格物。

此前单独跑通的可信分支源提交对应 [GitHub Actions 40282929026](https://github.com/timlincool/plush-pattern-lab/actions/runs/40282929026)，所有者验证了 Blender 4.3.2 真实图和 141 个 Python 测试，当前默认网格仍检出原有穿插。主分支提交发生后，应以合并后的 Action 运行作为本版本的最终证据。

## 当前与用户原设计不一致之处

原始角色有多个互相独立的软布/绒面/附件及明确面部配置；当前合成椭球只有主壳的技术试验，**不存在面部、耳朵、四肢、灰白连续云绒或雨滴附件**。既有私有外观候选与公开可制造数学实验目前仍是两条独立研究线；不要混称完成比例或给出虚假的图像相似度分数。

因此下一阶段的最小真实目标是：取得用户有权使用的目标组件网格/多视角约束，在受信环境建立清晰的**头／身／腿／蹄／耳／云绒底布／装饰承接**的缝合接口，随后每个接口都有 2D 纸样、实物和有限碰撞验证。未经用户明确授权，不把私人图片、模型或衍生视觉资产提交到这个公开仓库。
