# Stage 6：分离后躯与前部头颈的可制造母版 A/B（P3）

**状态：受信主干已经真实完成两种原模型截面引导试验，数字拼缝与研究SVG检验成功；25cm角色外观/真实材料/工厂均未验证，禁止直接裁布。**

## 1. 为什么必须换结构

原本的18片研究纸样（13下腹＋4片连续上身＋顶盖）虽然新增12组数字配缝全部等长，但[可信实算](STAGE6_UPPER_MOTHER_TOILE.md)发现原 Stage6 Z130→155mm 截面中心跳跃**71.386mm**，新的连续四片上身三维轮廓弦长与二维净缝最大相差**89.121mm**，并遗漏真实最高Z248.676mm与研究盖Z230mm间的18.676mm。数字配缝能闭合，不代表真实25cm羊驼会有正确的身体与头颈。

因此，保留已经证明来源真实的四蹄512边原接口及**13片下腹试布**，丢弃“从后身一直连到头顶”的单体上身假设，分开构造（1）后躯与肩片（2）前部颈/头布片，并明确二者的连接方案。

## 2. 固定源与真实剖面观测

数据只取公开Stage6 Blender SHA-256 `38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a` 生成的25% PLY SHA-256 `5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd`。原始四蹄源ID、四个源512边环与13片下腹、四条16段BAND接口均不可更改。

截面分层使用真实PLY顶点的Z±3mm和X/Y的1%～99%分位包络，而非有证明的源网格闭合裁切面：

- 后躯从旧BAND上缘研究高度Z100，参考真实Z115/125/135分别设计**4片TORSO纵向裁片**，Z135设一块试验肩盖。只有最底部的64段确切对应旧BAND的数字净缝，后续所有环形轮廓均为**新造型代理**。
- 前头颈是另一个体积：参考真实Z145/155/180/205/230分别设计**4片HEADNECK**，顶部配试验盖；原主壳Z230之上的装饰形状/耳朵头顶仍未完成纸样。
- 两个实体原源剖面Z135和Z145相隔10mm且相对平移。该空间距离不能直接被省略成一条神奇的同源缝线。
- 暂定研究缝份6mm；所有材料伸长、布厚、毛向、成品身高与工厂设备/缝法均未验证。特别注意**两个母版的外观不等于从原雕塑自动展平**。

## 3. 两个不同工艺方案

| 比较 | A：独立填充头身、外部缝接 | B：肩片开口、内部相通 |
| --- | --- | --- |
| 肩盖 | 实心SHOULDER-CAP；颈根仅画表面定位圈，**不剪孔** | 一块开有独立颈孔的SHOULDER-CAP，孔裁切线向孔心缩进6mm |
| 头颈下端 | 新CLOSED-NECK-BASE盖片封底，头单独填充 | 不封头底，增一块高**10mm**的COLLAR布筒；上口与头颈、下口与肩孔按64段拼合 |
| 返口与填充 | 头底封闭前独立填充，躯干通过旧BAND-3暂定42.49mm返口；表面手缝头根，实际连接强度未测试 | 从旧BAND-3试验返口尝试翻面/填充整个连接体；**42.49mm能否通过头颈尚未实测** |
| 头颈源根截面缩放 | 研究性0.74倍，表面导引线与肩片外缘需留缝份间隙 | 研究性0.64倍，颈孔与肩外缘必须保留**至少双份6mm缝份再加1mm研究裕量** |
| 新增单方案试布件 | TORSO 4 + 肩盖1 + HEADNECK 4 + 头顶盖1 + 颈底盖1 = **11片** | TORSO4 + 带孔肩盖1 + HEADNECK4 + 头顶盖1 + COLLAR1 = **11片** |
| 连同旧13片 | **24片／15张A4**（旧4页＋新增11页） | **24片／15张A4**（旧4页＋新增11页） |
| 当前判断 | 容易独立填充，但人手缝接、贴片强度、面部/肩云遮挡未验证 | 更像连续软体拼合，但源颈根需更大收缩、孔的缝份与翻面难度需实布验证 |

**两套方案是替代实验，不是同一个玩偶应叠加的22张新上身纸样。** A颈底盖片到肩盖导引线的接法是手工表面连接，数学周长相等无法证明机器净缝可直接车；B颈孔与COLLAR的64段边长由**同一新造的研究轮廓**计算，等长是设计上的数学构造，不能证明真实布料不拉伸。

原z145颈根在世界XY的真实轮廓比拟定肩孔大，必须报告缩放和移位引起的毫米级轮廓偏差；仅做几何拟合，**绝不推导“面料需要可拉伸35%”的没有实验依据的要求**。

## 4. 独立质量门禁和材料风险

纯数值 QA 必须通过的，是研究纸面**能自洽且可打印**：旧4个16段BAND↔TORSO下口、4条TORSO纵缝、4组TORSO→肩盖、4条HEADNECK纵缝、4组HEADNECK→头顶盖；再按方案审A的头底盖4组与肩表面导引线的差异，或审B的64段肩孔↔连接圈↔颈根双侧同长度、COLLAR闭筒边和双份缝份间隙。每项保留原序号、2D长度误差与多边形合法性证据。

**必须明确不通过的物理验收**：真实Stage6原主壳的连续面片并未展平；源截面本身可能属于不同体积；两种方案都可能改变前脸比例、耳根、胸云/背云与尾根；原真实蹄底3D未打版；返口无法用单个二维数字自证；原设计四视图对齐和材料/绒向/填棉/实体首样不在当前代码涵盖范围。

新模块：
- `patterns/stage6_split_volume_mother.py`：真实源分层、两个独立体积与两种颈口设计，输出原Z135/145偏移与源颈口的XY形状变化；
- `validation/stage6_split_volume_toile_qc.py`：独立检查纸样缝线、肩孔/导引线、缝份、A/B工艺区别、原13片来源与P4禁用状态；
- `patterns/stage6_split_volume_toile_svg.py`：每种结构11张实寸210×297mm A4，裁切/净缝/定位点、10×10mm印刷标尺。绝不静默缩放以塞进纸张；
- `scripts/build_stage6_split_volume_toile_ab.py`：只能读受信同Run原25% PLY和13片下腹源JSON，源蹄512边ID/XY重新验证后，输出两个结构、QC、22张备选试样SVG、双方案装配指南与每文件SHA-256 manifest。输出目录已存在即拒绝，绝不覆盖已复核证据。

**额外制造风险**：B孔的最短13.41mm，只比暂定的“2×6mm缝份＋1mm研究裕量”多**0.41mm**，真实布料厚度、弹性、切割与车缝公差尚未测量；不能因数学通过而说安全。A虽然无开孔，但头部独立填充后由手缝连接肩面，接缝承载和藏缝/云团覆盖尚未验证。原真实 Z135→145 源截面中心还相对移动了**35.46mm**；原顶Z248.676比这两方案的Z230试验盖高18.676mm。

**阶段决策：优先A做更廉价的双体积试布研究，不是把A定为最终工厂方案。** 其颈根缩放较小且不需要在肩盖剪洞；先以真实绒布和原角色四视角检查头肩比、填棉下沉、外部手缝连接强度及云团覆盖。B保留为内部连通工艺备选，但应先实际测试13mm边缘双缝份和42.49mm暂定返口能否翻出整个头颈，不能直接投入成品打版。

本轮独立源QC已对原 Artifact 中所有 **25个子文件计算SHA256并逐项与manifest一致**；原始研究 `source JSON`、`QC JSON`、`assembly_A_B.md` 和22张研究SVG文件完整哈希与可信Stage6运行号永久保存在[真实数据摘要](../experiments/stage6_two_volume_headneck_ab_20261110/summary.json)。导出的独立A/B包各包含旧下腹4页及自身新11页，且明确标注原雕塑造型不保真/真实面料未试验。
