## 为何需要真实曲面连通而不只是二维包围盒

Z230原主壳有中央+左右三个闭合截面，Z245仅左右两环。但“同一高度多环不相交”不意味着“三维必须裁成多片”。必须用**原三角面真实共享边**确定究竟在哪里分叉、哪里闭合，避免把源造型错误地生成大头盖或虚构可缝耳根。

新增 open-Z-slab 方法：

1. 选取与开放高度带有正交集的真实原三角面；仅当两个源三角面共享**在该高度带内具有非零覆盖的源边**时，才用并查集判定连通，不把仅单顶点/坐标接触作为一片。
2. 上下层每条闭环重新核对原 Vertex ID 对、真实插值XY和逐环SHA，要求整环映射到唯一曲面分量；区分1→1连续、1→多分叉、终止、出现和带内孤立。
3. 固定原Blend/25% PLY/同次section摘要及detail/同次41 Mesh JSON的来源哈希；输入篡改/跨实验拼装必须拒绝。
4. 输出 true_stage6_source_slab_head_ear.json 与 true_stage6_source_slab_head_ear.svg；后者是**拓扑研究示意，不能打印当工业纸样**。
