## 输入固定

公共 Stage6 Blend SHA-256：`38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a`；25% 代理 PLY SHA-256：`5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd`。来自同一次 Blender 工作流的 B 三片多径向裁片 summary/detail 用 SHA-256 相互校验，原始面ID/顶点ID/四蹄边界与径向缝线身份不变。

## 方法：用一个强制无折叠的研究基线剥离问题

1. 必须是原始三角网格 **单连通、单个闭合边界环的拓扑圆盘**；逐边比对输入边界与所有仅被一片面共享的源边，拒绝缺失、重复、非流形、零面积三角形、无效顶点。
2. 将各个边界源顶点按照原始3D边长累积比例映射到严格凸圆周（周长固定为3D边界周长）；内点解正权重均匀拉普拉斯方程 `L_ii * UV_i = -L_ib * UV_b`。
3. 按相同三角面/源顶点ID使用已有独立 `_quality` 审计 3D↔2D 边长相对误差、面翻转、近零面积、Shapely 全局非零面积重叠，以及源径向缝线在两片2D候选中的**两侧实际长度**。
4. 所有结果强制 `approved_industrial_paper_patterns=0`。**圆边界按原3D长度分配，径向缝双侧长度相等可能是构造效应，不证明内部面料能保持尺寸。** 也不验证云团遮盖、真实布料力学或实际手工缝制。

参考：Tutte (1963), *How to Draw a Graph*；Floater (2003), *Mean Value Coordinates*, DOI [10.1016/S0167-8396(03)00002-5](https://doi.org/10.1016/S0167-8396(03)00002-5)。保证性的数学条件包括有效的平面圆盘图嵌入、正权重和严格凸边界；**本项目仍通过数值翻面/相交审计，不直接声称任意坏网格也会通过**。
