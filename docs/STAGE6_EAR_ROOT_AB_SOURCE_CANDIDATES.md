# Stage6 耳根 A/B：真实源边闭环位置与狭窄缝份风险（P3）

**状态：真实锁定25% Stage6 PLY本地预审已测，受信 main 全套 Python/Blender 结果待确认。不是工厂纸样，也不是已设计的实体省道。** 本轮不是改UV求解器，而是对上轮确认的头部三分叉提出两个**可追溯原三角面切平面**，先否决不合理的耳根构造。

## 研究问题与同条件选线

上轮已从原主壳 116,568 个真实代理三角面发现 Z205→230 的单曲面 1→3 闭环、Z230→245 中央头顶闭合而左右环继续，并在完整41产品Mesh中发现高位耳/云层邻近。此次在**同一固定SHA、同一25%源代理**上探测 Z225.90 与 Z225.91，分别发现 1 与 3 个实际闭环，分叉位于这两个高度之间。不能把正好通过原源顶点的退化截面当可裁缝线。

两种初步耳根分离位置：

| 真实来源候选 | 左/右真源环长（mm） | 最窄XY包络（mm） | 到同高度中央头环XY最小间隙（mm） | 左右镜像XY轮廓Hausdorff |
| --- | --- | --- | --- | --- |
| **A 低位：Z230** | 45.517 / 45.511 | 11.002 / 10.996 | 17.651 / 17.652 | 0.043 mm |
| **B 高位：Z235** | 40.853 / 40.862 | 9.859 / 9.881 | 35.633 / 35.665 | 0.032 mm |

以上为**原始25% PLY源三角面与水平面相交**后按真实插值XY测得，并非渲染像素、物料反弹后的尺寸。B比A上移5mm，源缝周长每侧减少约4.65mm，但根部截面更窄；中央头环由约153.094mm缩小至81.577mm。两层之间实际2,708个带内原三角面形成3个彼此独立、上下1→1延续的曲面分量，源左右环不能被单一顶盖假造。

## 否决门禁：6mm缝份并非足够空间的证据

此前分体头身研究临时假设每侧6mm缝份。此次A/B**两侧耳根闭环XY最窄宽度都小于2×6mm**，在平面中存在双边缝份互相挤占的明显风险。此值只是定性的XY几何预筛：**不能把原曲面的XY投影宽度直接当作二维展平后的有效缝份**；相反也绝不能从数学上闭合、原3D净线相等、左右对称，就宣布可车缝。

每环保留真实源 Vertex ID 交叉边对、实际Z/XY、逐环SHA、4个等弧长测量位置；**没有任何正式剪口或纸样裁线**。四等分标记只用于研究可复算，不是工厂可用对位点。
