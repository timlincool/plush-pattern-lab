# Stage 6 真实主体：第一份覆盖整壳的四区候选拼缝图

**工程性质：全主壳 3D 面片分区与两两边长配对研究；不是工厂认可的 1:1 织物静止裁片。** 先阅读 [工厂总计划 P3](FACTORY_ROADMAP.md)、[已核实的真实25%主壳低模](../experiments/stage6_core_proxy_20261105/summary.json) 和 [实际五视角/BVH风险](STAGE6_PROXY_GEOMETRY_QA.md)。

## 本轮为何开始全壳分区

前一轮已获得源 SHA 固定、59,306 点／116,568 面的可复现**主体**低模研究代理，四个512点蹄接口世界坐标严格保留、单连通且无非流形边，并已通过独立非相邻三角面 BVH 与绕向审计。因此下一步应建立**整个主壳**的可解释结构，而不是反复调整单蹄局部的边权重。

## 真正执行的两组拆分 A/B

- X=0 是设计记录中的左右对称基准。
- 前向为负 Y；两个前蹄开口中心约在 Y=-34mm，两个后蹄约 Y=+81mm。两组仅改变前／后划分平面：**Y=20mm 和 Y=25mm**；这只是结构研究变量，不是已决定的可见生产缝线。
- 对每个真实三角面按重心所属象限标记 `left_front`、`left_rear`、`right_front`、`right_rear`。保留 PLY 原始面索引，以 RLE 保存 116,568 个面的分区归属。
- 用真实 mesh 每条边的两侧面号定义装配连接：区域交界处的共享边**天然为两侧同一条3D网格边**，统计实际 3D 毫米长度、端点、每一条连续连接链。严禁以临近点猜测缝线。
- 四区分别核对共享边连通分量、边界环数、欧拉数，以及是否各自含有**恰好一个完整512点蹄部原始开口**。任何开口被切断、分片不连通、跨对角区域相接、链分叉等都明确标失败。
- 两组之间仅以真实三维网络的边总长度作为**研究工作量指标**；少缝线未必等于更便宜或更漂亮（曲率、缝份、毛向、填棉和厂商工时仍需验证）。

## 关键制作限制

这些分区是以 3D 模型平面切割得到的**拓扑候选**。即使四个区域各连通、四条蹄口完整、相邻边精准匹配：

1. 各区域如果是有两个边界环的**环面带**，就仍需增加**径向切缝、省道或再分片**才能变成可实际铺布裁剪的简单形状；不能直接把投影轮廓作为1:1裁片。
2. 纵向/横向界线可能会形成**四线交汇点**，这是工艺复杂/鼓包风险，应通过更有意义的顺序接合结构、转移缝位或另加小片解决。
3. 自动 X/Y 分区可能穿过正脸、胸云下缘或局部毛向，必须回到**原设计图的四视角**调整可见缝位；不能认为完全对称在美术上就正确。
4. 3D 接合长度的逐段相等只是共用原网格边的结果，**尚未有二维布料净缝、缝份、缺口、返口、材料力学或实物打样**，绝不生成批准量产的 DXF 或 BOM。

## 可信复现

唯一输入为原 Stage6 公开 SHA 固定的 **25% PLY**：5b52e3fd09c83b19c5b9d95d6d8d859a147ff4deef90f1518f868d2e82e3a2dd，大小2227384字节。先在受信任 main 工作流内执行 Blender 源 SHA 核验、保四蹄低模生成、独立 BVH 和五视图检查，然后：

~~~bash
python scripts/propose_stage6_shell_panels.py \
  --input /tmp/stage6-proxy-candidates/core_shell_proxy_ratio_0.25.ply \
  --source-sha256 38a0be58ed4cb6b3af66fc392f4820d544851715002ee8520543d7e9fba85f3a \
  --output /tmp/four_region_seam_graph.json \
  --svg /tmp/four_region_3d_top_view.svg
~~~

SVG 输出采用毫米 **X/Y 顶视投影**，不是展开后的布料纸样，不得放入可裁版 DXF。JSON 列出所有分区面序号 RLE、源顶点 ID、两两相邻边、区域边界拓扑及各类未通过原因。实际结果归档后再写入 [长期进度](PRODUCTION_PROGRESS.json)。

**真正的下一步：**在不同部件接缝清晰的基础上，使每个区域通过设计合理的新增切缝/省道变成可展开的布片，加入返口/填棉、面料毛向及对位，创建真实 1:1 净缝线和严格双向缝长门禁，然后尽早向厂商做真实样布试缝。
