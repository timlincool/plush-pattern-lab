# 独立顶盖与底盖：由极点汇聚改为可检查的缝线环

此前的8/12瓣直接尖点拼接测试有 23/25 个法向翻转警告，全部来自裁片首末行。这个模块采用专业制版常见的**独立帽片/底片结构假设**，避免多人为合并到一个零半径顶点。

## 实际生成的内容

- `scripts/capped_gore_pattern.py`：合成椭球，上下各截去默认8°纬向端点，产生N片侧片（默认8片）和2片圆形帽片。
- 每个侧片的横向净缝线分成左右两段，分别与帽片2N边形的两条对应边保持**逐段等长**，顶点映射和缺口可以追踪。
- 侧片、帽片均保留净缝线与6mm（暂定）裁切缝份，输出 JSON，独立反例测试从6片覆盖至24片。
- `scripts/sewing_capped_poc_blender.py`：实验性将侧片与帽片组成低面数 Cloth Mesh；每片真正保留静止二维形态键，3D初始位置取已知合成目标加3mm位移；用**独立 loose edges 与 Sewing Springs**施加跨片缝合约束，不是程序直接将几何焊死。
- `sewing_quality.py` 使用对应合成目标顶点、静止二维位置与数值终态检查接缝间隙、刚体对齐目标误差、局部主伸长和相对初始法向翻面。仿真失败即留下诊断而不修改原研究样例。

## 为什么这还不能叫生产纸样？

**几何等长不是实际可缝制的证明**。帽片可能需要非圆的边界或省道、织物布纹方向、真实面料的经纬弹性、柔性衬布及绒毛遮盖。上下帽片的实际轮廓、受力方向与接触仍没有样布实测依据。

- 研究模型没有进行独立的真实纤维棉填充/回弹标定。
- 没有开展自碰撞和三维面片间交叉的完备检查，缝线接近不等于壳体完全焊接闭合。
- 目标辅助的初始3D位置不等于从照片推理出能缝合的模型。
- 研究阈值不得当作工厂安全伸长率或儿童玩具认证。

## 受证据约束的推进顺序

1. 先验证静态帽片分割、所有横向缝线配对与二维净裁片面积。
2. 再运行实际 Blender 4.3.2 `use_sewing_springs` 48帧，量化新旧极点结构的反例。
3. 如残存翻面，优先修改帽片细分、裁片分布与预定位，不靠提高材质刚度掩盖错误。
4. 只有有限数值正确且物理材料样布有标定，再把帽片用于真实羊驼和生产设计。

## 已实际跑过的 Blender 48 帧 A/B（2026-10-25）

[公开 Actions：12片与8片双帽片实际求解、研究筛选和产物](https://github.com/timlincool/plush-pattern-lab/actions/runs/40169745123)

| 结果 | 8片侧片 + 2帽片 | 12片侧片 + 2帽片 |
|---|---:|---:|
| 实际独立缝合弹簧 | 552 | 828 |
| 平均缝口间隙 | 0.000253mm | **0.000221mm** |
| 合成目标刚体对齐 RMS | 0.325mm | **0.216mm** |
| 主伸长偏差 P95 | 13.25% | **7.64%** |
| 相对初始法向翻面警告 | **0** | **0** |
| 零面积三角片 | **0** | **0** |
| 当前研究几何筛选 | 拒绝（应变） | **通过** |

这证明在已知合成目标预定位的受控算例中，两个圆形帽片避免了原先尖角汇聚造成的翻面；12片版本同时通过 *研究约束*。它不是独立的反向照片建模结果，没有使用真实布料物性或纤维棉，布片也没有焊接为真正闭合整体；不能宣称能够生产。

**研究用 SVG 输出：**

```bash
python scripts/capped_gore_pattern.py --panels 12 --pole-cut-deg 8 --out output/12caps.json
python scripts/export_capped_svg.py --input output/12caps.json --output output/12caps.svg
```

SVG采用毫米实体尺寸、净缝线虚线、暂定裁切线实线和简易对位标记，展示一片侧片（重复12次）以及一片顶盖/底盖；**禁止将研究标记当作工厂切割指令或定版材料公差**。
