# Stage 6 三角环带：固定弧长的切缝展平实验

**研究性质：** 二维低边长误差候选，不是可裁剪纸样、缝份或实际布料静止形状。

## 输入与第一性原理

真实 Stage 6 八组接缝均为连通三角环带（512 点内缝线、256 点外边界、768 个三角片）。[既有投影实测](../experiments/stage6_hoof_seams_20261030/triangle_band_projection.json)显示直接平面投影的 P95 逐边缩短为 25%～30%，不能直接裁切。

1. 从[公开 Stage 6 Release](https://github.com/timlincool/plush-pattern-lab/releases/tag/cloud-alpaca-stage6-visuals-20261028)匿名下载，并按固定 SHA-256 在 Blender 4.3.2、禁用自动执行环境核验；只从真实模型提取八个相邻三角环带。原始三维坐标仅存 Runner 临时目录，**不上传 Artifact、不进 Git**。
2. 保留 512 点内侧缝线的真实三维累积弧长 s 与原顶点身份，二维令 (x,y)=(s,0)。按周长 L 做周期配对，跨周期三角形采用**每面角点 UV 副本**，形成单条径向切缝。
3. 只优化外圈自由顶点，最小化所有唯一网格边的相对边长差平方和：E=Σ[(二维边长－三维边长)/三维边长]²。用 SciPy 稀疏最小二乘和明确位移边界；最多 60 次函数评估，不改变原始三维网格。
4. **独立检查** mean/P95/max 逐三角片边长相对误差、局部面片翻转/退化、二维三角面重叠、切缝数量、求解收敛与边界命中。P95 下降不能覆盖翻面或重叠失败；不会设置自动制造合格状态。
5. 输出 8 组评分 JSON 和 **1:1 mm SVG 研究可视化**；SVG 不是裁布外轮廓，不包含缝份、毛向或实体工艺审核。

## 运行

可信 main 的 `.github/workflows/stage6-hoof-seam-reference.yml` 在已有 Blender 模型验签、3D 缝环与三角面门禁通过后调用：

~~~bash
python scripts/unroll_stage6_triangle_band.py \
  --input local-output/verified-only-patches.json \
  --output local-output/stage6-slit-score.json \
  --svg local-output/stage6-slit-reference.svg
~~~

其中输入 JSON 由前一步可信 Blender 实时生成，且绑定固定模型 SHA-256，不是仓库预置数据。现有两种方案的几何条件不同，比较时必须逐项报告，**不能把边长失配当成实际布料主伸长**。

## 论文依据

- Mori & Igarashi, *Plushie: An Interactive Design System for Plush Toys*, ACM TOG (2007), https://doi.org/10.1145/1276377.1276433：纸样几何与缝制模拟必须构成反馈。
- *Bounded-Distortion Piecewise Mesh Parameterization*, ETH IGL, https://igl.ethz.ch/projects/parameterization/BDPMP/index.php：切缝分片与失真应联合考虑。本实现不宣称具有该论文的方法或严格失真上界。

| 局部环带 | 稀疏优化前 P95 | 稀疏优化后 P95 |
| --- | ---: | ---: |
| 主体环 0 | 8.73% | 3.47% |
| 主体环 1 | 9.29% | 3.46% |
| 主体环 2 | 17.97% | 2.77% |
| 主体环 3 | 17.98% | 2.73% |

全部 8/8 求解收敛、每组一条径向切缝、局部面片翻转数 0、二维三角面**检测到的重叠对数 0**。但原始完整 JSON 显示最坏单边误差仍约 **9.31%**，因此下轮应针对最差边/局部片段优化并保持独立重叠门禁；不可据 P95 晋升为生产纸样。注意此实验的“优化前”是同一周期接缝的初始猜测，与历史“整体平面投影”的约束不同，不能把两个 P95 直接当作严格 A/B 结论。

## 2026-11-02：最差边定位与有界 IRLS 对照

上一轮真实数据的**主体环 2、3 最大单边相对误差约 9.25% 和 9.31%**，远高于各自 P95 的 2.77% 和 2.73%。因此仅监控 P95 会掩盖局部最差边。新增两组**不改变原始模型、不提升纸样等级**的诊断：

- `baseline_edge_hotspots`：按唯一网格边保留最多八条最差边的**临时局部网格顶点序号**、3D 边长和带符号相对误差，并分为 `seam-seam`、`seam-outer`、`outer-outer`。原始三维坐标仍只在可信 Runner 临时目录，不保留在 Git 或 Artifact。
- `hotspot_weighted_variant`：冻结原始周期切缝、内侧 512 点真实弧长、自由顶点位移边界及同样的函数评估预算。根据基线每条唯一边的误差与其 P95 计算截断权重 `clip(|e|/max(P95,1e-8),1,4)`，从已经收敛的旧解额外运行一轮 SciPy 稀疏最小二乘。这是**受限迭代重加权实验**，并非理论 minimax 或 Bounded-Distortion 算法。

两项结果必须比较**max 与 P95 的逐边相对误差**，同时分别复核反向/塌陷三角片、二维三角片面积重叠对数、切缝数、收敛与优化边界命中。**新候选始终 `promoted_to_default=false`**；即使误差下降，也不能未经同条件 A/B 与后续实体验证就替换原有结果。所有数值仍是几何 2D/3D 边长差，**不是材料主伸长、实际试缝偏差或制造认证**。

可信主分支工作流在已有真实 Stage 6 切缝研究的 JSON/SVG 中保存这份有界诊断，绝不上传临时局部 3D 顶点文件。

## 2026-11-02：实测最差边都在外圈，改用小范围 A/B

[固定公开 Stage 6 的真实 A/B #41395441378](https://github.com/timlincool/plush-pattern-lab/actions/runs/41395441378) 证明 **8/8 个局部环带的最差边均为 `outer-outer`**。既有广泛再加权将主体环2/3的最差误差从 **9.25%/9.31%** 降到 **8.02%/7.99%**，但 P95 从 **2.77%/2.73%** 恶化到 **4.79%/4.74%**；两者均未出现面片翻转或重叠，但不能直接替换旧算法。

新增 `outer_worst_edge_variant` 作为**第三个、互不替代的研究对照**：仅选择外圈–外圈边中原始误差处于最高 2% 的少量边，赋固定 **1.75 倍**残差权重，其他边为 1；其余固定弧长、迭代预算、二维重叠与翻面检测完全不变。每组同时保留原基线、广泛加权及局部外圈加权的 max/P95 和安全否决计数。它**永远不会自动晋升**为默认结果；必须先以真实模型实测判断最差值是否下降且 P95 无明显退化，再讨论是否值得改变切缝位置或曲面分片。

误差单位仍是 2D 与原 3D 三角网格边长的**几何相对误差**，不是面料力学应变或真实玩偶试缝公差。

### Top 2% 外圈加权的真实否决（2026-11-02）

[受信任 Stage 6 Actions #41396074705](https://github.com/timlincool/plush-pattern-lab/actions/runs/41396074705) 已对同一固定 SHA 模型的八个环带完整实跑。每组仅加权 **6 条外圈–外圈边**，其余原始缝线、周期切缝、边长目标和求解预算不变。所有求解收敛，**0 面片翻转、0 检测到的二维重叠、单条切缝保持不变**。

| 主体环带 | 原方案最大误差 | 外圈 Top 2% 加权后 | 原 P95 → 新 P95 |
| --- | ---: | ---: | ---: |
| 环 2 | 9.25% | **10.29%（变差）** | 2.77% → 3.02% |
| 环 3 | 9.31% | **10.81%（变差）** | 2.73% → 2.97% |

8/8 组最大误差**均上升**，虽然 P95 牺牲比广泛加权方案小。这是**明确的研究负结果**：极少数边的局部加权会使优化器把误差转移到其他边，不能作为最大边长失配的可靠修复。详情见[固定源 SHA、逐组 max/P95 的 A/B 证据](../experiments/stage6_slit_unroll_20261101/outer_hotspot_ab_20261102.json)。原始默认参数、通过的接触/几何门禁、真实 Stage 6 文件和旧的完整评分保持不变。

**下一项应改变独立设计变量**：尝试不同径向切缝起点或局部曲面分片，并以同一原始模型、固定缝线、同预算 A/B 比较 **max、P95、面片翻转与二维重叠**。不再仅依赖调整残差权重，也不生成制造纸样。
