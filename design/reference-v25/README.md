# 原创云朵雨滴羊驼：外观第25轮公开参考

本目录经过来源与敏感文本的定向检查，是用户授权公开的七份历史参考资料，而非可缝的完整设计。

- `APPEARANCE_CONTRACT_v25.md`：约25cm外观目标、头身/耳尾/云绒、水滴及非动物材料约束；
- `face_embroidery_registration_v14.json`：眼、鼻和嘴的三维投影参考（尚未展平）；
- `drop_tab_registration23.json`：10枚水滴的候选锚点、颜色、短布片长度（尚未确定真实缝线）；
- `ear_fibre_sampling_analysis23.json`：耳部毛束重建取样差异；
- `structural_invariance_25_vs12.json`：原有冻结头身/云团的限定结构对照；
- `reproduction_verification25.json`：旧环境461物件的历史重建验收记录；
- `candidate25_manifest.json`：完整模型、数据、渲染的哈希及文件名，**不包含其二进制**；
- `PROVENANCE.json`：七个原文Git blob SHA及迁移状态。

[四张原型 PNG](images/README.md) 已进入公开 Git，SHA-256/PNG 元数据由测试保护；[Stage 6 四蹄可编辑 Blender 模型](https://github.com/timlincool/plush-pattern-lab/releases/tag/cloud-alpaca-stage6-visuals-20261028) 已迁入本仓库 Release。**尚未迁入的是旧六阶段从零恢复 ZIP 和原始生成脚本**；这些不阻塞从 Stage 6 开始新研发，但不得将已保存模型误称为完整程序化重建或制造验收。
